## 三、Agent Workflow 架构

### Workflow → Tool → Runtime 模型

```
RouterHarness.dispatch(action, task_id, context)
  → RouteEntry.tool_builder(ctx)      构建 ToolRegistry
  → RouteEntry.workflow_class()       实例化 Workflow
  → AgentTaskManager.enqueue(workflow, context, tools, sandbox)
    → threading.Thread(AgentRuntime.run)
      → workflow.plan(context)        生成 AgentStep[]
      → for each step:
          tool = ToolRegistry.get(step.tool)
          result = await tool.execute(**step.args)
          results[step.tool] = result.data
      → workflow.finalize(results)    WorkflowResult
```

### 现有 Workflow

| Workflow | action 路由 | plan() 步骤 |
|---|---|---|
| `ArchAnalystWorkflow` | `"analyze"` | analyze_community ×N → generate_diagram ×N → generate_overview → save_community_results |
| `ArchSentinelWorkflow` | `"track_start"` | diff_architecture |
| `ArchSentinelWorkflow` | `"track_stop"` | diff_architecture → summarize_changes |
| `ComponentAnalystWorkflow` | `"analyze_components"` | analyze_component ×N (含分析+保存) |

### 所有 AgentTool

| Tool 名称 | 类 | 是否 LLM | workflow |
|---|---|---|---|
| `analyze_community` | `_AnalyzeCommunityTool` | YES | ArchAnalyst |
| `generate_diagram` | `_GenerateDiagramTool` | NO | ArchAnalyst |
| `generate_overview` | `_GenerateOverviewTool` | YES | ArchAnalyst |
| `save_community_results` | `_SaveResultsTool` | NO | ArchAnalyst |
| `diff_architecture` | `_DiffTool` | NO | ArchSentinel |
| `summarize_changes` | `_SummarizeTool` | YES | ArchSentinel |
| `analyze_component` | `_AnalyzeComponentTool` | YES | ComponentAnalyst |

### LLM Adapter

```
所有 AgentTool 的 LLM 调用 → create_llm_chat_fn(multi_db, model_id) → _chat()
  → LLMService.sync_chat(messages, model_id)       [llm_service.py:616]
    → _sync_call_for_retry(model, messages, ...)   [llm_service.py:645]
      → provider.chat_sync()                       同步 HTTP 调用
  → 返回 str (纯文本)
  → 写入 llm_call_logs + model_daily_usage
```

## 五、上下文管理系统

### AnalysisContext 类 (`analysis_context.py`)

**4 层认知模型** (当前未被任何 Workflow 使用 — 死代码):

| 层级 | 方法 | 加载的数据 | 输出 |
|---|---|---|---|
| project | `get_project_layer()` | graph_node (files, symbols, languages) + graph_doc (INCLUDE L0, CALL L0) | ContextLayer(what/how/why) |
| community | `get_community_layer(comm_id)` | graph_doc (node_list, edge_list) + graph_node (node names) → Hub 计算 → children | ContextLayer |
| file | `get_file_layer(file_path)` | graph_node (同类文件的所有符号) → kind 分布 → exports → functions | ContextLayer |
| symbol | `get_symbol_layer(symbol_name)` | graph_node + graph_edge (callers, callees) | ContextLayer |

**LLM 格式化**: `format_for_llm([layer1, layer2, ...])` → 结构化的中文 Markdown 文本

**当前所有 Workflow 都不使用 AnalysisContext** — 各路径自行拼凑上下文。

## 六、存储架构

### 主要表与写入路径

```
community_llm_results  ← 路径 B (前端 runTask) + 路径 C (ArchAnalyst save) + 路径 D (analyzeComponents sync)
component_analysis     ← 路径 D (analyzeComponents 主存储)
report_subdocs         ← 路径 F (regenerateDoc) + 路径 F (saveOverallDoc)
projects.summary       ← 路径 G/H (generateProjectSummary)
llm_call_logs          ← 所有路径 (每次 LLM 调用)
model_daily_usage      ← 所有路径 (每次 LLM 调用，累加)
report_interaction_log ← 所有路径 (分析会话)
arch_timeline          ← 路径 I (track_start/stop)
```

### community_llm_results 表

```sql
CREATE TABLE community_llm_results (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id     TEXT NOT NULL,
    edge_type   TEXT NOT NULL,          -- 'INCLUDE' | 'CALL'
    comm_lv     TEXT NOT NULL,          -- 'L0' | 'L1' | 'L2'
    comm_id     TEXT NOT NULL,
    name        TEXT,                   -- LLM 生成的组件名称
    summary     TEXT,                   -- LLM 生成的功能概要
    mermaid     TEXT,                   -- Mermaid 图代码
    plantuml    TEXT,                   -- PlantUML 图代码
    model_id    TEXT,
    template_id TEXT,
    name_manual TEXT,                   -- 用户手动编辑的名称
    created_at  TEXT DEFAULT (datetime('now')),
    updated_at  TEXT DEFAULT (datetime('now')),
    UNIQUE(task_id, edge_type, comm_lv, comm_id)
);
```

### component_analysis 表

```sql
CREATE TABLE component_analysis (
    id                INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id           TEXT NOT NULL,
    component_id      TEXT NOT NULL,
    component_type    TEXT NOT NULL DEFAULT 'community',
    analyzed_name     TEXT,             -- LLM 分析名称
    functional_summary TEXT,            -- LLM 功能概要
    status            TEXT DEFAULT 'pending',
    analyzed_at       TEXT DEFAULT (datetime('now')),
    UNIQUE(task_id, component_id)
);
```

### llm_call_logs 表

```sql
CREATE TABLE llm_call_logs (
    id TEXT PRIMARY KEY,
    session_id TEXT,
    request_id TEXT NOT NULL,
    model_id TEXT,
    provider TEXT,
    model_name TEXT,
    mode TEXT NOT NULL,                 -- 'chat' | 'tools' | 'structured'
    template_id TEXT,
    messages_json TEXT,                 -- 完整 prompt (role + content)
    response_content TEXT,              -- 截断至 100000 字符
    tool_calls_json TEXT,
    token_prompt INTEGER,
    token_completion INTEGER,
    token_total INTEGER,
    latency_ms INTEGER,
    status TEXT CHECK(status IN ('success', 'error', 'aborted')),
    error_message TEXT,
    created_at TEXT DEFAULT (datetime('now'))
);
```
