### 2.86 内部库 — TopoScript 动画引擎 (45 文件)

> 路径别名 `@topo-animation` → `src/lib/topo-animation/`

| 模块 | 文件数 | 主要文件 | 作用 |
|------|--------|---------|------|
| **统一入口** | 1 | `index.ts` | 桶导出全部公共 API |
| **core/** | 4 | `types.ts`, `AnimationEngine.ts`, `StateMachine.ts`, `index.ts` | 核心类型/动画引擎/状态机 |
| **core/instructions/** | 4 | `InstructionTypes.ts`, `InstructionFactory.ts`, `InstructionExecutor.ts` | 30+ 动画指令类型/工厂/执行器 |
| **compiler/** | 7 | `TopoTokenizer.ts`, `TopoParser.ts`, `TopoAST.ts`, `TopoSemanticChecker.ts`, `TopoCodeGenerator.ts`, `compile.ts` | TopoScript 风格 B 编译器 (词法→语法→语义→代码生成) |
| **compiler/plugin/** | 5 | `PluginInterface.ts`, `VariableScope.ts`, `FunctionRegistry.ts`, `ConditionEngine.ts` | 插件系统 (变量/函数/条件) |
| **renderer/** | 10 | `IRenderer.ts`, `SVGRenderer.ts`, `CanvasRenderer.ts`, `theme/`, `layout/` | SVG/D3 + Canvas/PixiJS v8 双渲染器、4 种布局算法 (force/hierarchy/grid/circular) |
| **animator/** | 2 | `TopoAnimator.ts` | 动画序列播放器 (play/pause/stop/seek) |
| **runtime/** | 4 | `TimelineController.ts`, `EventEmitter.ts`, `ScriptBuilder.ts` | 运行时：时间轴/事件/链式 API |
| **export/** | 4 | `exportImage.ts`, `exportHTML.ts`, `exportJSON.ts` | 导出：PNG/SVG/HTML/JSON |
| **utils/** | 4 | `easing.ts`, `error.ts`, `logger.ts` | 缓动函数/错误处理/日志 |

**关键设计决策**:
- 语法风格：**风格 B** (声明式 `node A at (x,y)`) 为主
- PixiJS v8 适配：CanvasRenderer 已从 v7 升级
- 路径别名：`@topo-animation` (vite.config.ts + tsconfig.json)
- 使用：`import { compile, createAnimationEngine } from '@topo-animation'`
