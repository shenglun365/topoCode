### PlantUML 渲染增强 (2026-05-24)

**新增能力**:
- **语法清洗**: `_sanitize_plantuml()` 转换 LLM 输出的非标准语法为有效 PlantUML
- **自动包装**: 自动添加缺失的 `@startuml`/`@enduml` 包装
- **PlantUML 自定义 base64 编码**: 使用专用字母表 `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz-_`
- **错误处理**: `SubDocViewer.vue` 显示渲染错误和原始代码，便于调试

**支持转换的 LLM 输出格式**:
1. `A [src] -xxx> B [dst]` → `[src] --> [dst] : xxx`
2. `file name.ext -->` → `"name.ext" -->` (文件名中的点自动加引号)
3. 裸文件名 `router.js` → `"router.js"` (带有扩展名的标识符自动加引号)

**配置**:
- 依赖版本固定: `plantuml==1.2024.7` (requirements.txt)
- 渲染路径: 优先远程服务器，支持本地 jar 回退
- **适用位置**: LLMChatFlow 输出的 PlantUML 代码块、报告文档中的图例

## 七、渲染架构

### 混合架构 + 统一 RenderManager

```
渲染类型          执行环境          理由
─────────────────────────────────────────────────────────────
Mermaid          Web Worker        同步解析阻塞，Worker 完美适配
D3 力导向布局    Web Worker        300+ tick 迭代计算密集
D3 DOM 更新      主线程            Worker 返回坐标后批量更新 DOM
PlantUML         Python 后端       需 Java 环境，已有进程
PIXI.js          主线程 Canvas     WebGL 需主线程，独立 Canvas 不阻塞
CSS 动画         GPU 合成          transform/opacity 不阻塞 JS
TopoScript 动画   AnimationEngine   编译→指令→渲染 全链路 (Phase 6 已完成)
```
