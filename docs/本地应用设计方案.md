# TopoCode 本地应用设计方案

## 概述

Electron 桌面应用中新增：登录/注册、用户 Profile、资源中心。

**通信方式**：HTTP 直连 Web 服务器（不走 ZMQ/IPC）。

**开发模式**：内置 Mock 数据，无需 Web 服务器即可开发。

---

## 架构

```
Vue 3 App ─── HTTP ───→ Web Server (FastAPI + MySQL)
   │                          ↑
   ├── auth-service.ts        │
   ├── resource-service.ts    │
   └── mock fallback ─────────┘  （dev 模式直接返回本地数据）
```

## Store 设计

### auth-store.ts

```typescript
interface User {
  id: number
  username: string
  email: string
  avatar?: string
}

interface AuthState {
  user: User | null
  token: string | null
}

// 方法
login(email: string, password: string): Promise<boolean>
register(username: string, email: string, password: string): Promise<boolean>
logout(): void
loadSession(): void    // 从 localStorage 恢复
fetchProfile(): Promise<void>  // 刷新用户信息
```

### resource-store.ts

```typescript
interface Resource {
  id: number
  title: string
  description: string
  category: string
  thumbnail_url?: string
  download_count: number
  is_free: boolean
  created_at: string
}

interface ResourceState {
  resources: Resource[]
  currentResource: Resource | null
  loading: boolean
  categories: string[]
  activeCategory: string
}

// 方法
fetchResources(): Promise<void>
fetchDetail(id: number): Promise<void>
getDownloadUrl(id: number): Promise<string>    // 返回 OSS URL
setCategory(cat: string): void
```

## 页面访问控制

| 页面 | 是否需要登录 | 未登录行为 |
|---|---|---|
| `/login`, `/register` | 否 | — |
| `/home`, `/code`, `/analysis`, `/user` | 否 | 正常访问 |
| `/resource`（浏览列表） | 否 | 可浏览列表，下载按钮提示登录 |
| `/resource/:id`（详情） | 否 | 同上 |
| 下载按钮 | **是** | 弹出登录引导或跳 `/login` |

## 状态恢复流程

```
App 启动
  ↓
authStore.loadSession()  → 检查 localStorage 是否有 token
  ↓
有 token → fetchProfile() 验证 token 有效性
           ↓ 有效              ↓ 失效
        设置 user         清除 token，视为未登录
  ↓
无 token → 视为未登录，自由浏览除下载外的所有页面
```
