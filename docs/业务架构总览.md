## 二、业务域划分

系统按功能分为 6 个核心业务域:

| 业务域 | 核心价值 | 前端页面 | 后端 IPC 方法数 | 关键数据表 |
|---|---|---|---|---|
| **项目管理** | 项目导入/浏览/分组/文件树 | HomePage | 15 + 7(group) | projects, source_files, project_groups |
| **代码分析** | AST解析/符号提取/调用图/依赖图/社区发现 | HomePage(Analysis tab) | 25 | analysis_tasks, base_node, graph_node, graph_doc |
| **报告生成** | LLM结构化分析/社区AI分析/子文档 | AnalysisPage / ReportHome | 16 | report_subdocs, community_llm_results, file_summaries |
| **LLM对话** | AI智能体对话/会话管理/工具调用 | CoderPage | 2+7+6 | llm_sessions, llm_messages, analysis_sessions |
| **知识库** | 知识文档/图谱/维度分类 | KnowledgePage | 7 | knowledge_docs |
| **设置管理** | AI模型/代理/技能/主题/通用配置 | UserPage | 14 | model_configs, agent_configs, skill_configs |

### 跨域共享层

| 共享能力 | 实现位置 | 说明 |
|---|---|---|
| ZMQ IPC 通信 | zmq_server.py / zmq-router.ts / preload.ts | DEALER:5671 RPC + PUB:5680 事件推送 |
| Pinia 状态管理 | 14 stores | project / analysis / report / chat / knowledge / settings / theme / navigation / panel / window / status / debug / funcGroup / onboarding |
| LLM 网关 | llm_service.py / llmClient.ts / useLlmChat | 3 种模式流式输出 |
| FastAPI 网页服务 | web_server.py / viewer.html / code.html | 浏览器端查看文档和源码 |
| 主题系统 | theme.ts / ThemeManager.vue / ThemeEditor.vue | Catppuccin Mocha + 自定义主题 |

### 3.3 社区分析批处理流

```
CommunityAnalysisPipeline.vue
  │
  ├─ edgeType: call / include
  ├─ level: L0 / L1 / ... (tabs)
  ├─ 社区分页列表
  │
  ├─ analyzeSelected() / retrySingleCommunity()
  │    │
  │    ├─ reportStore.analyzeSelected()
  │    │    │
  │    │    ├─ for each selected community:
  │    │    │   ├─ set status = 'running'
  │    │    │   ├─ prompt_manager.render(community_analysis template, variables)
  │    │    │   ├─ llm.chat (streaming)
  │    │    │   ├─ on chunk → store progress
  │    │    │   ├─ on done → saveCommunityResult (IPC)
  │    │    │   │   └─ JSON.parse(JSON.stringify()) 深拷贝防 Proxy 序列化失败
  │    │    │   │   └─ analysis_store.bulk_insert_llm_results (INSERT OR REPLACE)
  │    │    │   └─ on complete → c.selected = false (自动取消选中)
  │    │    │
  │    │    └─ syncSelections() → 同步 UI 状态
  │    │
  │    ├─ 结果持久化到 community_llm_results (UNIQUE(task_id, edge_type, comm_lv, comm_id))
  │    │
  │    └─ loadCommunities() 合并策略:
  │        └─ merge in-place (保留对象引用, 避免中断中的分析丢失)
  │
  └─ 子文档查看:
       ├─ SubDocViewer.vue → renderedContent() (正则渲染)
       │   ├─ GFM 表格 / 链接 / 标题 / hr
       │   ├─ community-link: [text](##community:edgeType:commId)
       │   └─ diagram-placeholder: mermaid / plantuml → renderAllDiagrams()
       │
       └─ 浏览器端查看 (web_server.py / viewer.html)
           └─ marked.js + normalizeDiagramCode() (7规则统一)
```

### 5.3 6步分析管道 (analyst_runner.py)

```
Step1: AST解析 ──›  tree-sitter → base_node (AST节点)
  │
Step2: 符号提取 ──›  按语言提取 function/class/macro/method → graph_node
  │
Step3: 调用图 ───›  语言级 caller→callee 边 → graph_node (call_relation)
  │
Step4: 依赖图 ───›  import/include/require 边 → graph_node (depend_relation)
  │
Step5: 社区发现 ──›  NetworkX Louvain → graph_doc + community_hierarchy
  │                  (递归子社区, 最大6级, 过滤hub/orphan)
  │
Step6: 结果汇总 ──›  analysis_reports (JSON格式)
```

**支持语言 (11种):** C, C++, Python, JavaScript, TypeScript, Java, Go, Rust, C#, PHP, Swift

**解析器架构:**
- `parsers/code_parser/parser_factory.py` → `LanguageParserFactory` (LanguageConfig协议)
- `parsers/call_parser/extractor_factory.py` → `CallGraphExtractor` (每种语言单独实现)
- `parsers/dependence_parser/extractor_factory.py` → `DependencyExtractor` (每种语言单独实现)
- `parsers/symbol_parser/language_handlers.py` → `LanguageHandler` (每种语言单独实现)

## 七、数据流与状态映射

### 7.1 关键数据流

```
用户操作 → Component.dispatch() → Store.action → ipc.ts → 
  preload → ipcMain → zmq-router → zmq_server → Python handler → 
  store/ → SQLite → 返回 → 更新 Store.状态 → 响应式更新 UI
```

### 7.2 关键状态矩阵

| 业务概念 | 持久化位置 | 运行时状态 | 同步策略 |
|---|---|---|---|
| 项目列表 | `projects` 表 | projectStore.projects | 首次加载 + 手动刷新 |
| 分析任务 | `analysis_tasks` 表 | analysisStore.tasks | 轮询 + 事件推送 |
| 社区运行时 | (不持久化) | reportStore.tasks[taskId] | onMounted restoreFromDb() |
| 社区AI结果 | `community_llm_results` 表 | reportStore.tasks[taskId].communities[].llmMap | loadCommunities() merge |
| 管道状态 | `report_subdocs` (pipeline_{taskId}) | reportStore.tasks[taskId].pipeline* | loadPipelineState() |
| 子文档内容 | `report_subdocs` 表 | SubDocViewer.doc | 按需加载 |
| LLM会话 | `llm_sessions` + `llm_messages` | chatStore.sessions | 首次加载 + 创建时保存 |
| 模型配置 | `model_configs` 表 | settingsStore.models | 首次加载 + CRUD后刷新 |
| 用户主题 | `user_node_styles` 表 | themeStore.theme | 初始化加载 |

### 7.3 关键约束

| 约束 | 原因 | 实施位置 |
|---|---|---|
| `saveCommunityResult` 必须深拷贝 | Electron Structured Clone无法序列化Pinia Proxy | ipc.ts:289 + preload.ts:246 |
| `loadCommunities` in-place merge | 保留对象引用, 防止分析中断丢失 | reportStore.loadCommunities() |
| `running` 总是初始化为 false | 不允许从持久化状态恢复运行中 | reportStore restoreFromDb() |
| 最大窗口数=1 | 资源控制+ZMQ连接管理 | window-manager.ts:MAX_WINDOWS |
| 任务创建去重 | 防止重复提交 | 前端 if(running) return + 后端 status check |
| Python进程不自杀 | checkAndKillPortOccupant过滤自己PID | python-bridge.ts |
