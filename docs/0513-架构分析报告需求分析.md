# 架构分析报告 — 需求分析

> 日期: 2026-05-13
> 状态: 已确认，衍生事项评估完成

## 一、需求概述

在主工作区 AnalysisPage 以 tab 形式打开分析报告，每份报告独立一个 tab。tab 内支持按社区层级/分组/展开深度筛选条件，查询后端获取关系图数据，由 TopoScript 引擎渲染可视化图。点击图的节点/边/社区，在右侧"代码索引"面板以对话流形式追加内容，支持 AI 辅助代码解释。

### 3.7 数据流全链路

```
用户点击报告 → 打开 report tab (AnalysisPage)
    ↓
tab 加载 → 后端获取任务信息 + 可用社区层级列表
    ↓
用户选择社区层级 + 分组 ID + 展开深度 → 点击查询
    ↓
前端请求 → 后端 get_community_graph(task_id, edge_type, comm_lv, comm_ids[], depth)
    ↓
后端查询 graph_doc → 按深度展开 → 提取 node_list/edge_list → 返回结构化数据
    ↓
前端计算图数据哈希 → 命中缓存则直接取 TopoScript，否则用 TopoScript API 组装 → 缓存
    ↓
AnimationEngine 渲染
    ↓
用户点击节点/边/社区 → 后端获取符号详情 + 代码抽样
    ↓
右侧代码索引面板追加对话消息（基本信息 + AI 解释按钮）
```

## 四、TopoScript API 能力评估

### A1. addNode 形状/颜色 — ✅ 无需扩展

**现有能力完整:**
- `AddNodePayload.style: Record<string, any>` 接受任意样式属性
- `NodeStyle` 类型已定义 `shape`, `fillColor`, `strokeColor`, `strokeWidth`, `radius`, `width`, `height`
- `NodeShape` 枚举: `circle | rect | diamond | triangle | hexagon | ellipse | image`
- `SVGRenderer.drawShape()` 已读取并应用所有样式属性

**使用方式:**
```typescript
InstructionFactory.addNode({
  nodeId: 'A',
  label: 'Service A',
  style: { shape: 'rect', fillColor: '#4A90D9', strokeColor: '#2C5F8D', width: 100, height: 40 }
});
```

### A2. addEdge 有向箭头 — ⚠️ 需小修

**现有能力:**
- `EdgeStyle` 已定义 `markerEnd`, `markerStart`, `strokeDasharray`, `type: 'straight'|'curved'|'orthogonal'`
- `SVGRenderer.renderArrowMarkers()` 已预定义 `#arrow` 标记
- `renderEdges()` 已读取 `markerEnd`: `d.style?.markerEnd ? 'url(#arrow)' : 'none'`

**差距:**
1. 仅一种箭头标记 `#arrow`，不支持多种样式
2. `markerEnd` 是布尔判断，不支持指定标记 ID
3. `markerStart` 定义了但渲染器未读取
4. 箭头颜色固定为 `theme.edge.defaultColor`，不支持按边自定义

**扩展方案:**
```typescript
// SVGRenderer.renderArrowMarkers() — 增加多种标记
// - #arrow-filled (默认实心), #arrow-open (空心), #arrow-thick (粗箭头)

// renderEdges() — markerEnd 改为字符串匹配
.attr('marker-end', d.style?.markerEnd ? `url(#${d.style.markerEnd})` : 'none')
.attr('marker-start', d.style?.markerStart ? `url(#${d.style.markerStart})` : 'none')

// 动态颜色: 按边的 color 创建对应颜色的标记
```

### A3. 嵌套分组 (社区嵌套) — ⚠️ 需中修

**现有能力:**
- `CreateGroupPayload` 已定义 `groupId`, `nodeIds`, `edgeIds`, `label`, `style`
- `GroupState` 已定义 `childGroupIds`, `nestingLevel`
- `GroupMetadata` 已定义 `parentGroupId`, `childGroupIds`
- `StateMachine.applyGroupDelta()` 已实现组的创建/更新/删除
- `SVGRenderer.renderGroups()` 已实现组的渲染

**关键差距: `InstructionExecutor.executeStateChange()` 缺少组的 case 分支**

`createGroup`, `updateGroup`, `removeGroup` 三条指令会被执行器丢弃（落入 default → 报 "Unknown instruction type"）。

**扩展方案:**
```typescript
// 1. InstructionExecutor.executeStateChange() — 添加组处理
case 'createGroup': {
  if (!delta.groups) delta.groups = { createOrUpdate: [] };
  delta.groups.createOrUpdate.push({
    id: payload.groupId,
    nodeIds: payload.nodeIds,
    edgeIds: payload.edgeIds,
    label: payload.label,
    style: payload.style,
    metadata: payload.metadata,
  });
  break;
}
case 'removeGroup': {
  if (!delta.groups) delta.groups = { remove: [] };
  delta.groups.remove.push(payload.groupId);
  break;
}

// 2. CreateGroupPayload — 新增 parentGroupId
export interface CreateGroupPayload {
  groupId: GroupId;
  nodeIds: NodeId[];
  edgeIds?: EdgeId[];
  parentGroupId?: GroupId;  // NEW
  label?: string;
  style?: Record<string, any>;
  metadata?: Record<string, any>;
}

// 3. StateMachine.applyGroupDelta() — 处理 parent/child 关系
// 创建时: 将子组 ID 加入父组 childGroupIds，设置 nestingLevel

// 4. SVGRenderer.renderGroups() — z-ordering
// 父组先渲染，子组后渲染
```

### A4. 节点/边点击事件 — ⚠️ 需中修

**现有能力:**
- `SVGRenderer` 已绑定 `click`/`mouseenter`/`mouseleave` 事件
- `SVGRenderer.setNodeClickHandler(handler)` 已暴露
- `AnimationEngine.getRenderer()` 可获取渲染器实例
- `AnimationEngine` 有 EventEmitter 基础设施

**关键差距: 事件链断裂**

```
SVGRenderer (捕获点击) → setNodeClickHandler (已存在)
  → AnimationEngine (未调用 setNodeClickHandler) ❌
    → EventEmitter (未发射 node-click) ❌
      → useAnimation (未订阅) ❌
        → AnimationStage.vue (未 emit) ❌
```

**扩展方案 (Option A — 引擎级事件，推荐):**
```typescript
// 1. AnimationEngine.init() — 绑定渲染器事件到 EventEmitter
if (this.options.renderer === 'd3') {
  (this.renderer as SVGRenderer).setNodeClickHandler((nodeId) => {
    this.emitter.emit('node-click', { nodeId });
  });
  (this.renderer as SVGRenderer).setNodeHoverHandler((nodeId) => {
    this.emitter.emit('node-hover', { nodeId });
  });
}

// 2. useAnimation.ts — 订阅并暴露
const onNodeClick = ref<((nodeId: string) => void) | null>(null)
engine.on('node-click', (data: { nodeId: string }) => {
  onNodeClick.value?.(data.nodeId)
})
// return 中添加 onNodeClick

// 3. AnimationStage.vue — 添加 emits
const emit = defineEmits<{
  'node-click': [nodeId: string]
  'node-hover': [nodeId: string | null]
  'edge-click': [edgeId: string]
}>()
```

### A5. 缩放/平移 — ⚠️ 需小修

**现有能力:**
- `SVGRenderer` 已集成 D3 zoom: `d3.zoom().scaleExtent([0.1, 4])`，鼠标滚轮 + 拖拽平移默认启用
- `SVGRenderer.zoomToLevel(level)` 已实现
- `SVGRenderer.fitToScreen(padding)` 已实现

**差距: 未暴露到 Vue 层**

`IRenderer` 接口无 zoom 方法 → `AnimationEngine` 无代理 → `useAnimation` 无暴露 → `AnimationStage` 无控件

**扩展方案:**
```typescript
// 1. IRenderer — 可选方法
zoomToLevel?(level: number): void;
fitToScreen?(padding?: number): void;
resetZoom?(): void;

// 2. AnimationEngine — 代理方法
zoomToLevel(level: number) { this.renderer?.zoomToLevel?.(level); }
fitToScreen(padding?: number) { this.renderer?.fitToScreen?.(padding); }
resetZoom() { this.renderer?.fitToScreen?.(); }

// 3. useAnimation — 暴露
function zoomToLevel(level: number) { engine?.zoomToLevel(level) }
function fitToScreen(padding?: number) { engine?.fitToScreen(padding) }

// 4. AnimationStage.vue — 工具栏添加缩放控件
```

### A6. 运行时布局切换 — ⚠️ 需小修

**现有能力:**
- `applyLayout()` 纯函数，支持 `force-directed | hierarchy | grid | circular`
- `AnimationEngine.load()` 中调用一次 `applyLayout()`

**差距: 无运行时切换方法**

引擎架构是"编译一次、播放多次"，`StateMachine.compile()` 产出固定 `AnimationState[]`。

**扩展方案 (Option A — 重排当前状态):**
```typescript
// AnimationEngine — 新增方法
switchLayout(layout: LayoutType): void {
  const currentState = this.getCurrentState();
  if (!currentState || !this.renderer) return;

  const laidOutNodes = applyLayout(
    layout, currentState.nodes, currentState.edges,
    this.options.width, this.options.height
  );
  currentState.nodes = laidOutNodes;
  this.renderer.render(currentState);
}
```

### 架构可扩展性评估

**指令系统设计优秀，扩展路径清晰:**

1. **开放联合类型** — `AnimationInstruction` 是判别联合，新增指令需: 新 Payload 接口 → 新类型别名 → 加入联合 → 加入 `InstructionPayloadMap` → Executor 新增 case → Factory 新方法
2. **`style: Record<string, any>`** — 故意宽泛，新样式属性无需改 schema
3. **`metadata: Record<string, any>`** — 同上，可附加任意数据
4. **`NodeStyle`/`EdgeStyle` 索引签名** — `[key: string]: any` 进一步向前兼容
5. **`IRenderer` 接口最小化** (init/render/destroy) — 新渲染器无需改引擎
