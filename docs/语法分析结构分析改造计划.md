# 语法分析与结构分析改造计划

> 基于 codegraph-0.9.9 对标分析，全面重构语法分析子系统。

---

## 零、改造原则

1. **一刀切除旧通道**：移除 `parser.py`（手写 DFS 遍历）、`.scm` Query 管线（`parse_with_queries.py` + 30 个 `.scm` 文件）、`extract_global_symbols.py`（旧版）、`extract_call_graph.py`（旧版）、`extract_dependency_graph.py`（旧版）、`call_parser/`、`dependence_parser/`、`symbol_parser/` 等所有旧代码。
2. **以 codegraph LanguageExtractor 模式为蓝本**：声明式 AST 节点类型映射 + 语言钩子函数 + 统一核心 Walker。
3. **不兼容旧输出**：graph_node 表结构、字段命名均按最优方案重新设计，不保留兼容层。
4. **一次性到位**：语言支持、关系类型、scope 链、两阶段解析、框架感知均按完整方案实现。

## 四、TreeSitterWalker 核心引擎

### 4.1 状态管理

```python
class TreeSitterWalker:
    def __init__(self, file_path: str, source: bytes, language: str):
        self.file_path: str
        self.source: bytes
        self.language: str
        self.extractor: LanguageExtractor
        self.nodes: list[Node] = []
        self.edges: list[Edge] = []
        self.unresolved_refs: list[UnresolvedReference] = []
        self.node_stack: list[str] = []  # scope 追踪
```

### 4.2 节点类型分发（核心循环）

```python
def visit(self, node: SyntaxNode):
    node_type = node.type
    ex = self.extractor
    skip_children = False

    # 1. 函数定义
    if node_type in ex.function_types:
        if self._inside_class_like():
            self._extract_method(node)
        else:
            self._extract_function(node)
        skip_children = True

    # 2. 方法定义
    elif node_type in ex.method_types:
        self._extract_method(node)
        skip_children = True

    # 3. 类定义
    elif node_type in ex.class_types:
        classification = ex.classify_class(node) if ex.classify_class else "class"
        dispatch = {
            "class":     self._extract_class,
            "struct":    self._extract_struct,
            "enum":      self._extract_enum,
            "interface": self._extract_interface,
            "trait":     self._extract_trait,
        }
        dispatch[classification](node)
        skip_children = True

    # 4. 接口
    elif node_type in ex.interface_types:
        self._extract_interface(node)
        skip_children = True

    # 5. 结构体
    elif node_type in ex.struct_types:
        self._extract_struct(node)
        skip_children = True

    # 6. 枚举
    elif node_type in ex.enum_types:
        self._extract_enum(node)
        skip_children = True

    # 7. 类型别名
    elif node_type in ex.type_alias_types:
        self._extract_type_alias(node)
        # 可能下钻为 struct/enum/interface（Go typedef）

    # 8. 变量
    elif node_type in ex.variable_types and not self._inside_class_like():
        self._extract_variable(node)

    # 9. 字段
    elif node_type in ex.field_types and self._inside_class_like():
        self._extract_field(node)

    # 10. 属性
    elif node_type in ex.property_types and self._inside_class_like():
        self._extract_property(node)

    # 11. 导入
    elif node_type in ex.import_types:
        self._extract_import(node)

    # 12. 调用表达式
    elif node_type in ex.call_types:
        self._collect_call(node)

    # 13. 实例化 (new)
    elif node_type in ex.instantiation_types:
        self._collect_instantiation(node)

    # 14. 继承 (在类/接口内由 _extract_inheritance 处理)

    # 15. 装饰器 (在声明节点由 _extract_decorators 处理)

    # 16. Rust impl_item
    elif node_type == "impl_item":
        self._extract_rust_impl(node)

    if not skip_children:
        for child in node.named_children:
            self.visit(child)
```

### 4.3 创建节点 & contains 边

```python
def _create_node(self, kind: NodeKind, name: str, ast_node: SyntaxNode,
                 **extra) -> Node | None:
    if not name:
        return None

    node_id = _make_id(self.file_path, kind, name, ast_node.start_point[0] + 1)
    qualified_name = self._build_qualified_name(name)
    
    new_node = Node(
        id=node_id,
        kind=kind,
        name=name,
        qualified_name=qualified_name,
        file_path=self.file_path,
        language=self.language,
        start_line=ast_node.start_point[0] + 1,
        end_line=ast_node.end_point[0] + 1,
        start_col=ast_node.start_point[1],
        end_col=ast_node.end_point[1],
        **extra,
    )
    self.nodes.append(new_node)

    # 自动生成 contains 边
    if self.node_stack:
        parent_id = self.node_stack[-1]
        self.edges.append(Edge(source=parent_id, target=node_id, kind=EdgeKind.CONTAINS))

    return new_node
```

### 4.4 qualifiedName 构建

```python
def _build_qualified_name(self, name: str) -> str:
    parts = []
    for nid in self.node_stack:
        parent = self._find_node(nid)
        if parent and parent.kind not in (NodeKind.FILE, NodeKind.MODULE):
            parts.append(parent.name)
    parts.append(name)
    return "::".join(parts)
    # 例：src/utils.py::MathHelper::calculateTotal
```

### 4.5 继承提取（核心：支持 10+ 种 AST 模式）

```python
def _extract_inheritance(self, node: SyntaxNode, class_id: str):
    """统一继承/实现提取"""
    # Python: class Foo(Base1, Base2):
    # Java: class Foo extends Base implements IFace
    # C++: class Foo : public Base, private Mixin
    # C#: class Foo : BaseItem, IPlugin
    # TS: class Foo extends Base implements IFace
    # JS: class Foo extends Base
    # Kotlin: class Foo : Bar, Baz
    # Swift: class Foo: Bar, ProtoA, ProtoB
    # ObjC: @interface Foo : NSObject <ProtoA, ProtoB>
    # PHP: class Foo extends Bar implements Baz
    # Dart: class Foo extends Bar implements Baz
    # Go: struct embedding, interface embedding
    # Rust: trait Supertrait bound
    # Ruby: class Foo < Bar

    for child in node.named_children:
        # extends_clause / class_heritage / base_class_clause / superclass
        # implements_clause / super_interfaces / interfaces
        # argument_list (Python)
        # trait_bounds (Rust)
        # base_list (C#)
        # delegation_specifier (Kotlin)
        # inheritance_specifier (Swift)
        # parameterized_arguments (ObjC protocol list)
        # Go struct embedding (field_declaration without field_identifier)
        
        kind, name = self._classify_inheritance(child, node)
        if kind and name:
            self.unresolved_refs.append(UnresolvedReference(
                from_node_id=class_id,
                reference_name=name,
                reference_kind=kind,  # EdgeKind.EXTENDS or EdgeKind.IMPLEMENTS
                ...
            ))
```

### 4.6 调用提取

```python
def _collect_call(self, node: SyntaxNode):
    caller_id = self.node_stack[-1] if self.node_stack else None
    if not caller_id:
        return

    callee_name = self._resolve_callee(node)
    # 支持多种 AST 模式:
    # - call_expression.function → 直接调用 foo()
    # - call_expression.function(member_expression) → obj.method()
    # - method_invocation(object + name) → Java obj.method()
    # - message_expression → ObjC [obj method]
    # - selector_expression → Go selector
    # - member_call_expression → PHP $obj->method()
    # - navigation_expression → Kotlin navigation
    # - field_expression → C/C++ obj.method() / ptr->method()

    if callee_name:
        self.unresolved_refs.append(UnresolvedReference(
            from_node_id=caller_id,
            reference_name=callee_name,
            reference_kind=EdgeKind.CALLS,
            line=node.start_point[0] + 1,
            column=node.start_point[1],
        ))
```

    for child in decl_node.named_children:
        if child.type in ("decorator", "annotation", "marker_annotation"):

            self.unresolved_refs.append(...)

## 五、Resolution 阶段

### 5.1 两阶段流程

```
Phase 1: 提取阶段 (Walker)
  ├─ 每个文件独立解析
  ├─ 创建 nodes[] (含 node_id, kind, name, qualified_name, scope)
  └─ 收集 unresolved_refs[]

Phase 2: 解析阶段 (ResolutionEngine)
  ├─ 加载所有文件提取结果
  ├─ 策略 1: local scope 查找（文件内向上遍历作用域链）
  ├─ 策略 2: import 跨文件解析（从 export 表匹配）
  ├─ 策略 3: qualified name 全限定名匹配
  ├─ 策略 4: 框架感知解析（Django URLs, Spring Controllers 等）
  ├─ 生成 edges[]: calls, imports, extends, implements, type_of, ...
  └─ 输出 resolved edges → GraphEmitter → DB
```

### 5.2 ResolutionEngine

```python
class ResolutionEngine:
    def resolve(self, all_tables: dict[str, FileSymbolTable]) -> list[Edge]:
        """统一解析所有 unresolved references，生成 resolved edges"""
        edges = []
        
        # 建立全局索引
        symbol_index = self._build_symbol_index(all_tables)    # name → [Node]
        export_index = self._build_export_index(all_tables)    # file → exported names
        qualified_index = self._build_qualified_index(all_tables)  # qualifiedName → Node
        
        for table in all_tables.values():
            for ref in table.unresolved_refs:
                target = None
                
                # 策略 1: 本地作用域链
                target = self._resolve_local(ref, table)
                
                # 策略 2: import 跨文件
                if not target:
                    target = self._resolve_via_import(ref, table, export_index, symbol_index)
                
                # 策略 3: qualified name
                if not target:
                    target = qualified_index.get(ref.reference_name)
                
                # 策略 4: 框架感知
                if not target:
                    target = self._resolve_via_framework(ref, table)
                
                if target:
                    edges.append(Edge(
                        source=ref.from_node_id,
                        target=target.id,
                        kind=ref.reference_kind,
                        provenance="resolution",
                    ))
        
        return edges
```

```python
class FrameworkResolver(ABC):
    """框架解析器 — 识别框架模式，生成额外节点和边"""

    name: str          # "django", "react", ...
    language: str      # "python", "typescript", ...

    @abstractmethod
    def detect(self, file_tables: dict) -> bool:
        """检测项目是否使用此框架（检查特征文件/导入）"""

    @abstractmethod
    def extract(self, table: FileSymbolTable) -> list[Node]:
        """从单文件提取框架特有节点（route, component 等）"""

    @abstractmethod
    def resolve(self, ref: UnresolvedReference, tables: dict) -> Node | None:
        """解析框架特有的引用模式"""

    def post_extract(self, all_nodes: list[Node]) -> list[Edge]:
        """全局后处理，生成合成边（如 middleware 链）"""
```

### 6.3 动态合成器 (DynamicSynthesizer)

```python
class DynamicSynthesizer:
    """补充静态分析无法捕获的边"""

    def synthesize(self, nodes: list[Node], edges: list[Edge],
                   tables: dict[str, FileSymbolTable]) -> list[Edge]:
        synthetic_edges = []

        # 1. 回调注册: on("event", handler) → calls 边
        synthetic_edges += self._synthesize_callbacks(nodes, tables)

        # 2. EventEmitter: emitter.on(event, fn) → 连接
        synthetic_edges += self._synthesize_event_emitters(nodes, tables)

        # 3. 匿名类→接口桥接: new Runnable() { run() {} } → implements
        synthetic_edges += self._synthesize_anonymous_impls(nodes, edges)

        # 4. React: setState → render
        synthetic_edges += self._synthesize_react_rerender(nodes, edges)

        return synthetic_edges
```

## 九、6 步分析流程（简化后）

```
analyst_runner.py:_do_parse()

Step 1: AST 解析 (并行)
    TreeSitterWalker.extract() × N 文件
    → graph_node (nodes) + unresolved_refs
    ↓
Step 2: 符号提取 (废除，Step 1 已产出 nodes)
    ↓
Step 3: 调用图 + 依赖图 + 继承 + ... (废除独立步骤)
    ResolutionEngine.resolve()
    → graph_edge (calls, imports, extends, implements, ...)
    ↓
Step 4: 动态合成
    DynamicSynthesizer.synthesize()
    FrameworkResolver.post_extract()
    → 补充合成 edges
    ↓
Step 5: 社区分析 (保持)
    analyze_communities() on graph_node + graph_edge
    ↓
Step 6: 结果汇总 (保持)
    统计 → analysis_reports 表
```

简化后调用入口变为：

```python
from parsers.core.walker import TreeSitterWalker
from parsers.core.resolver import ResolutionEngine
from parsers.core.synthesis import DynamicSynthesizer
from parsers.languages import EXTRACTORS

# Step 1: 并行解析
walker = TreeSitterWalker(file_path, source_bytes, language, EXTRACTORS[language])
extraction = walker.extract()  # → nodes + unresolved_refs
emitter.write_nodes(extraction.nodes)

# Step 2-3: 解析 + 写入边 (文件收集完后统一执行)
resolver = ResolutionEngine(all_tables)
edges = resolver.resolve()
emitter.write_edges(edges)

# Step 4: 合成
synthesizer = DynamicSynthesizer(FRAMEWORK_RESOLVERS)
synthetic_edges = synthesizer.synthesize(all_nodes, edges, all_tables)
emitter.write_edges(synthetic_edges, provenance='synthesizer')
```
