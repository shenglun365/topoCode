# SkillManager 组件设计

> SKILL 校验拓展开关，管理设计契约校验扩展

---

## 1. 组件职责

- 展示 SKILL 列表
- 支持启用/禁用 SKILL
- 执行任务时按需启用校验规则

## 3. Props / Emits

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `skills` | `SkillConfig[]` | 内置默认列表 | SKILL 配置列表 |

### Emits

| 事件 | 载荷 | 说明 |
|------|------|------|
| `toggle` | `{ id: string, enabled: boolean }` | 切换启用状态 |

### 数据结构

```typescript
interface SkillConfig {
  id: string;
  name: string;
  description: string;
  enabled: boolean;
}

// 内置 SKILL 清单
const DEFAULT_SKILLS: SkillConfig[] = [
  { id: 'sig-check',   name: '严格函数签名校验', description: '校验生成代码的函数签名是否与 Spec 定义一致，包括参数类型、返回值', enabled: true },
  { id: 'dep-check',   name: '依赖合规检查',     description: '检查生成代码是否引入未授权的依赖库，确保符合项目依赖规范', enabled: true },
  { id: 'sec-enforce', name: '安全规范强制',     description: '强制生成代码符合知识库中定义的安全标准和加密规范', enabled: false },
  { id: 'anim-gen',    name: '同步生成动画脚本', description: '要求 Agent 在实现代码的同时生成对应的动画脚本，用于演示和教学', enabled: false },
  { id: 'style-check', name: '代码风格检查',     description: 'ESLint / Prettier / Black 等代码风格规则校验', enabled: false },
];
```

## 4. 子组件

| 组件 | 说明 |
|------|------|
| `SkillCard` | SKILL 卡片 (名称/描述/开关) |
| `ToggleSwitch` | 复用：启用/禁用开关 |

## 5. 交互逻辑

- 点击开关 → 切换启用状态，即时生效
- 启用状态持久化到本地存储
- 用户创建 Agent 任务时，可选是否启用 SKILL 校验

## 6. 样式规范

- SkillCard: padding 14px, margin-bottom 10px
- 标题 13px 粗体，
- 描述 11px，颜色 `var(--text-muted)`
- 开关右对齐
