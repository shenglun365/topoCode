# ChatMessage 组件设计

> 消息气泡，展示单条对话消息

---

## 1. 组件职责

- 渲染用户/AI 消息
- 支持多种消息类型 (文本/代码/卡片)
- 提供复制/重试操作

## 2. 布局结构

```
用户消息:
┌─────────────────────────────────┐
│  请分析这个项目的架构           │
│                        [10:30] │
└─────────────────────────────────┘

AI 消息:
┌─────────────────────────────────┐
│ AI 助手                  [10:31]│
│                                 │
│  根据分析，该项目采用...         │
│                                 │
│  ```python                      │
│  def example():                 │
│      pass                       │
│  ```                            │
│                                 │
│  [复制] [重试]                  │
└─────────────────────────────────┘
```

## 3. Props / Emits

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `message` | `ChatMessage` | - | 消息数据 |
| `showActions` | `boolean` | `true` | 是否显示操作按钮 |

### Emits

| 事件 | 载荷 | 说明 |
|------|------|------|
| `copy` | `{ messageId: string }` | 复制消息 |
| `retry` | `{ messageId: string }` | 重试消息 |

## 4. 子组件

| 组件 | 说明 |
|------|------|
| `MessageHeader` | 消息头部 (发送者/时间) |
| `MessageContent` | 消息内容 |
| `MessageActions` | 操作按钮 |
| `CodeBlock` | 代码块 (复用) |

## 5. 交互逻辑

- 点击"复制" → 复制消息内容到剪贴板
- 点击"重试" → 重新发送上一条用户消息
- 代码块：支持语法高亮和复制

## 6. 样式规范

- 用户消息：右对齐，蓝色背景
- AI 消息：左对齐，灰色背景
- 消息最大宽度：80%
- 代码块：等宽字体，圆角背景
