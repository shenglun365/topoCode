### 端口分配

| 端口 | Socket 类型 | 方向 | 用途 |
|------|-------------|------|------|
| 5670 | ROUTER | Main Process 监听 | 主进程路由，分发到不同后端 |
| 5671 | DEALER | Python 监听 | RPC 请求处理 |
| 5672 | DEALER | Agent 监听 | Agent 任务分发 (预留) |
| 5680 | PUB | Python 发布 | 事件推送 |
| 5681 | SUB | Main Process 订阅 | 事件接收 |

## 二、消息帧格式

### 2.1 ZeroMQ 请求帧 (ROUTER → DEALER)

```
┌──────────┬────────────┬──────────┬─────────────────┐
│ Frame 0  │ Frame 1    │ Frame 2  │ Frame 3         │
│ IDENTITY │ REQUEST_ID │ METHOD   │ PARAMS_JSON     │
│ (bytes)  │ (string)   │ (string) │ (string)        │
└──────────┴────────────┴──────────┴─────────────────┘
```

**请求示例**:
```
["core"] ["req-001"] ["project.list"] ["{}"]
```

### 2.2 ZeroMQ 响应帧 (DEALER → ROUTER)

```
┌──────────┬────────────┬───────────────┬──────────────┐
│ Frame 0  │ Frame 1    │ Frame 2       │ Frame 3      │
│ IDENTITY │ REQUEST_ID │ RESULT_JSON   │ ERROR_JSON   │
│ (bytes)  │ (string)   │ (string/null) │ (string/null)│
└──────────┴────────────┴───────────────┴──────────────┘
```

**成功响应**:
```
["client-abc"] ["req-001"] [{"id":"proj-1","name":"topoOne-ui",...}] ["null"]
```

**错误响应**:
```
["client-abc"] ["req-001"] ["null"] [{"code":-32001,"message":"项目不存在"}]
```

### 2.3 ZeroMQ 事件帧 (PUB → SUB)

```
┌─────────┬─────────────┬────────────┐
│ Frame 0 │ Frame 1     │ Frame 2    │
│ TOPIC   │ EVENT_TYPE  │ DATA_JSON  │
│ (string)│ (string)    │ (string)   │
└─────────┴─────────────┴────────────┘
```

**事件示例**:
```
["task"] ["progress"] [{"taskId":"task-1","progress":45}]
```

### 2.4 TypeScript 类型定义

```typescript
// 请求
interface ZMQRequest {
  identity: string            // 后端标识 (core/agent-1/agent-N)
  requestId: string           // 唯一请求 ID (UUID)
  method: string              // 方法名 (模块.操作)
  params: Record<string, any> // 参数
}

// 响应
interface ZMQResponse<T = any> {
  requestId: string           // 对应请求 ID
  result: T | null            // 成功结果
  error: ZMQError | null      // 错误信息
}

interface ZMQError {
  code: number                // 错误码
  message: string             // 错误消息
  data?: any                  // 额外信息
}

// 事件
interface ZMQEvent {
  topic: string               // 主题 (task/project/backend)
  eventType: string           // 事件类型 (progress/complete/error)
  data: Record<string, any>   // 事件数据
  timestamp: number           // 时间戳
}
```

### 4.2 数据类型

```typescript
interface AnalysisTask {
  id: string
  projectId: string
  type: 'full-parse' | 'ast-gen' | 'call-chain' | 'dataflow' | 'dep-analysis'
  name: string
  status: 'done' | 'running' | 'pending' | 'error'
  progress?: number           // 0-100
  total?: number              // 总步骤
  current?: number            // 当前步骤
  error?: string | null
  createdAt: string
  updatedAt: string
  favorite?: boolean
  pinned?: boolean
  tags?: string[]
  results?: AnalysisResult    // 分析结果 (可选)
}

interface AnalysisResult {
  ast?: any                   // AST 树
  callChain?: CallChainItem[] // 调用链
  dependencies?: {            // 依赖分析
    modules: string[]
    files: string[]
  }
  dataflow?: DataFlowItem[]   // 数据流
}

interface CallChainItem {
  from: string                // 调用方
  to: string                  // 被调用方
  function: string            // 函数名
}

interface DataFlowItem {
  source: string              // 数据源
  target: string              // 数据目标
  data: string                // 数据描述
}
```

### 9.1 任务事件 (topic: "task")

| 事件类型 | 数据 | 说明 |

| `error` | `{ taskId, status, error }` | 任务失败 |
| `terminal` | `{ taskId, line, type }` | 终端输出 (预留) |
| `validation` | `{ taskId, label, passed }` | 校验结果 (预留) |

interface TaskProgressEvent {
  taskId: string
  progress: number    // 0-100
  total: number
  current: number
  status: string
}

  taskId: string

  progress: number
}

  taskId: string
  status: string      // 'error'
  error: string
}
