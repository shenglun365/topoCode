# 用户中心功能文档

## 概述

用户系统分为两大部分：**客户端（Electron Vue 前端）** 和 **独立 Web 服务端**。客户端优先 Mock 模式开发，接口通过 HTTP 直连服务端，走 CORS 跨域。

## 架构

```
本地应用 (topoOne-ui, git 管理)
  ├── /login         登录页（全屏卡片）
  ├── /register      注册页（邮箱/手机验证码 + 邀请码）
  ├── /user          用户中心（个人资料 + 资源中心）
  └── /settings      设置（AI配置/通用/导入/主题等）

  ActivityBar:
    用户中心 (UserIcon)  → /user
    设置     (CogIcon)  → /settings

独立服务端 (topoOne-cloud/, 不纳入 git)
  ├── FastAPI + MySQL + Redis + JWT
  ├── /api/auth/*      注册/登录/验证码
  ├── /api/user/*      profile/积分/推广统计
  ├── /api/resources/* 资源列表/下载（含定价模式）
  └── /admin/*         资源管理后台 (Jinja2)
```

## 已开发功能清单

### 1. 注册登录

| 功能 | 前端 | 服务端 API |
|------|------|-----------|
| 邮箱验证码发送 | RegisterPage 60s 倒计时 | POST `/api/auth/send-email-code` |
| 手机验证码发送 | RegisterPage 60s 倒计时（仅国内） | POST `/api/auth/send-sms-code` |
| 注册（含验证码校验） | 邮箱/手机双通道 + 邀请码输入 | POST `/api/auth/register` |
| 登录 | 邮箱+密码，loading/error 态 | POST `/api/auth/login` |
| 登录日志记录 | — | login_logs 表记录 IP+DeviceId |
| 设备指纹 | `X-Device-Id` header（Electron uuid / browser localStorage） | IP+DeviceId 双重限流 |

### 2. 个人资料

| 头像占位 | `ProfileTab.vue` | 首字母圆形头像 |
| 退出登录 | `ProfileTab.vue` | 清除 localStorage token，跳转首页 |

### 3. 推广分享

| 功能 | 组件/API | 说明 |
|------|----------|------|
| 邀请码生成 | 服务端 `models/user.py` | 注册时自动生成 8 位字母数字码 |
| 邀请码展示 | `ProfileTab.vue` | 粗体等宽字体显示 |
| QR 码 | `ProfileTab.vue`（qrcode 库前端生成） | 内容为分享链接 |
| 复制分享链接 | `ProfileTab.vue` | `navigator.clipboard` |
| 微博分享 | `ProfileTab.vue` | `window.open` 微博分享页 |
| 微信分享 | `ProfileTab.vue` | 弹出 QR 码放大提示扫码 |
| 小红书分享 | `ProfileTab.vue` | 复制链接 + 提示粘贴 |
| 推广统计 | `ProfileTab.vue` | 邀请人数 / 活跃人数 / 奖励积分 |
| 注册时填邀请码 | `RegisterPage.vue` | URL 参数 `?ref=xxx` 自动填入 |
| 邀请奖励积分 | 服务端 `routes/auth.py` | 被邀请人注册 → 邀请人 +50 分 |
| 推广事件日志 | `referral_events` 表 | 记录邀请人、被邀请人、奖励积分 |

### 4. 积分系统

| 功能 | 实现 | 说明 |
|------|------|------|
| 积分余额 | 服务端 `users.points` 字段 | 登录/Profile API 返回 |
| 积分流水 | `points_log` 表 | 每次变动记录 balance_after |
| 积分奖励：邀请注册 | `award_points()` +50 | 注册时触发 |
| 积分消耗：下载资源 | `spend_points()` 扣积分 | 下载时触发 |
| 防刷：下载令牌 | `download_tokens` 表 | 每次兑换 = 3 次下载 / 24h 有效 |
| 配置阈值 | `DOWNLOAD_TOKEN_MAX_USES=3`, `DOWNLOAD_TOKEN_TTL_HOURS=24` | 环境变量，不对外暴露 |

### 5. 资源中心

| 功能 | 前端 | 服务端 |
|------|------|--------|
| 资源列表 | `ResourceCard.vue` Grid 网格 | GET `/api/resources` |
| 分类筛选 | 按钮行（全部/微服务/前端等） | `?category=` 参数 |
| 资源详情 | `ResourceDetail.vue` Modal | GET `/api/resources/:id` |
| 下载 | 按定价模式分流 | GET `/api/resources/:id/download` |
| 未登录提示 | 条幅 + 登录按钮 | — |
| 定价标签 | 卡片右上角/详情页展示 | `pricing_model` 字段 |
| Mock 数据 | 10 条，覆盖免费/积分/付费三种模式 | — |

### 6. 资源定价模式

| 模式 | 枚举值 | 下载行为 | 前端展示 |
|------|--------|----------|----------|
| 免费 | `free` | 直接返回 OSS 预签名 URL | "下载" |
| 积分兑换 | `points` | 扣积分 → 创建下载令牌 → 返回 URL | "XX 积分兑换" / "积分不足" |
| 付费 | `paid` | 返回 402（暂未开通支付） | "¥XX 购买" |
| 订阅会员 | `subscription` | 返回 402（暂未开通） | "订阅会员" |
| 专属定制 | `custom` | 返回 402 | "联系客服" |

### 7. 防刷与限流

| 层级 | 对象 | 窗口 | 上限 | 实现 |
|------|------|------|------|------|
| IP | send-* | 60s / 1h / 24h | 1 / 5 / 20 | Redis INCR + EXPIRE（Lua 脚本） |
| DeviceId | send-* | 60s / 24h | 1 / 10 | Redis INCR + EXPIRE |
| IP | register | 24h | 5 | Redis |
| DeviceId | register | 24h | 3 | Redis |
| User | download | 24h | 50 | Redis |
| — | 下载令牌 | 24h | 3 次/令牌 | MySQL `download_tokens` 表 |
| — | OSS 预签名 URL | 5min | — | 服务端 oss_service.py |
| — | 黑名单 | 30 天 | — | Redis `ban:ip:` / `ban:device:` |

### 8. 资源管理后台

| 功能 | 路由 | 说明 |
|------|------|------|
| 管理员登录 | `/admin/login` | 硬编码 ADMIN_TOKEN（`.env`） |
| 资源列表 | `/admin/resources` | 分页表格 |
| 新增资源 | `/admin/resources/new` | 表单含定价模式选择器 |
| 编辑资源 | `/admin/resources/:id/edit` | 同上 |
| 删除资源 | POST `/admin/resources/:id/delete` | 确认后删除 |

### 9. 服务端限流 API

| 方法 | 路径 | 认证 | 限流 |
|------|------|------|------|
| POST | `/api/auth/send-email-code` | 否 | IP(60s×1 / 1h×5) + Device(60s×1 / 24h×10) |
| POST | `/api/auth/send-sms-code` | 否 | 同上 |
| POST | `/api/auth/register` | 否 | IP(24h×5) + Device(24h×3) |
| POST | `/api/auth/login` | 否 | IP(5m×10) |
| GET | `/api/user/profile` | JWT | — |
| GET | `/api/user/referral-info` | JWT | — |
| GET | `/api/user/points` | JWT | — |
| GET | `/api/user/referral-stats` | JWT | — |
| GET | `/api/resources` | 否 | — |
| GET | `/api/resources/:id` | 否 | — |
| GET | `/api/resources/:id/download` | JWT | User(24h×50) + 令牌检查 |

## 服务端目录结构

```
topoOne-cloud/
├── app/
│   ├── main.py              # FastAPI 入口 + CORS
│   ├── config.py            # MySQL/Redis/JWT/OSS/限流配置
│   ├── database.py          # MySQL init_db（6 张表 + 迁移）
│   ├── redis_client.py      # Redis 连接
│   ├── rate_limiter.py      # Lua 脚本 + 多级限流 + 黑名单
│   ├── email_service.py     # SMTP 邮件验证码
│   ├── sms_service.py       # 阿里云短信验证码
│   ├── models/
│   │   ├── user.py          # User CRUD + 积分 + 推广统计 + 登录日志
│   │   ├── resource.py      # Resource CRUD + 定价字段
│   │   └── token.py         # 下载令牌创建/消耗/过期清理
│   ├── routes/
│   │   ├── auth.py          # 注册/登录/验证码/邀请奖励
│   │   ├── user.py          # profile/积分/推广信息
│   │   ├── resources.py     # 列表/详情/按定价模式下载
│   │   └── admin.py         # 资源管理后台 CRUD
│   └── services/
│       ├── jwt_service.py   # JWT 签发/验证
│       └── oss_service.py   # OSS 预签名 URL
├── templates/               # Jinja2 管理后台模板
├── requirements.txt
├── .env.example
└── deploy/
```

## 数据库表

| 表 | 用途 | 核心字段 |
|----|------|----------|
| users | 用户 | id, username, email, phone, password_hash, referral_code, points, referred_by, is_active |
| resources | 资源 | id, title, category, pricing_model, points_cost, price_cny, subscription_tier, oss_url |
| referral_events | 推广事件 | referrer_id, referred_user_id, bonus_type, points_awarded |
| points_log | 积分流水 | user_id, amount, balance_after, reason, ref_id |
| login_logs | 登录日志 | user_id, ip, device_id |
| download_tokens | 下载令牌 | user_id, resource_id, points_spent, max_downloads, remaining, expires_at |
