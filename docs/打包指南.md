# TopoOne UI - 多平台打包指南

## 快速开始

### 本地测试打包 (当前平台)
```bash
# 仅打包不解压 (测试用)
npm run package

# 完整打包 (生成安装程序)
npm run dist
```

### 指定平台打包
```bash
# Linux
npm run dist:linux

# Windows
npm run dist:win

# macOS
npm run dist:mac

# 全部平台 (需要对应环境)
npm run dist:all
```


## 平台特定要求

### Linux (Ubuntu/Debian)

**系统要求**:
- Ubuntu 18.04+ / Debian 10+
- glibc 2.28+

**依赖安装**:
```bash
sudo apt update
sudo apt install -y \
    build-essential \
    libgtk-3-dev \
    libnotify-dev \
    libnss3 \
    libxss1 \
    libxtst6 \
    xdg-utils
```

**打包命令**:
```bash
npm run dist:linux
```

**测试运行**:
```bash
cd release/linux-unpacked
./topoone-ui --no-sandbox
```

### Windows

**方式 1: 在 Windows 上直接打包**
```bash
npm run dist:win
```

**方式 2: 在 Linux 上交叉编译 (需要 Wine)**
```bash
# 安装 Wine
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install -y wine64 wine32

# 打包
npm run dist:win
```

**方式 3: 使用 GitHub Actions (推荐)**
```yaml
# .github/workflows/build.yml
name: Build
on: [push]

jobs:
  build-windows:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npm run dist:win
      - uses: actions/upload-artifact@v4
        with:
          name: windows-build
          path: release/
```

### macOS

**系统要求**:
- macOS 12.0+ (Monterey)
- Xcode Command Line Tools

**依赖安装**:
```bash
xcode-select --install
```

**打包命令**:
```bash
# Intel Mac
npm run dist:mac

# Apple Silicon Mac (自动检测)
npm run dist:mac
```

**注意**: macOS 打包需要在 macOS 环境下执行，无法交叉编译。

## 图标配置

### 准备图标

| 平台 | 文件 | 格式 | 尺寸 |
|------|------|------|------|
| Linux | `build/icon.png` | PNG | 512×512 |
| Windows | `build/icon.ico` | ICO | 256×256 (含多尺寸) |
| macOS | `build/icon.icns` | ICNS | 512×512 |

### 生成图标

**Linux**:
```bash
# 使用 ImageMagick
convert -size 512x512 xc:'#1e1e2e' \
  -pointsize 36 -fill '#cdd6f4' \
  -gravity center -annotate 0 'TopoOne' \
  build/icon.png
```

**Windows**:
```bash
# 使用 Inkscape (Linux)
inkscape build/icon.png --export-filename=build/icon.ico --export-filename=256x256

# 或使用在线工具
# https://convertio.co/png-ico/
```

**macOS**:
```bash
# 创建 iconset 目录
mkdir -p build/icon.iconset

# 生成不同尺寸
sips -z 16 16 build/icon.png --out build/icon.iconset/icon_16x16.png
sips -z 32 32 build/icon.png --out build/icon.iconset/icon_16x16@2x.png
sips -z 32 32 build/icon.png --out build/icon.iconset/icon_32x32.png
sips -z 64 64 build/icon.png --out build/icon.iconset/icon_32x32@2x.png
sips -z 128 128 build/icon.png --out build/icon.iconset/icon_128x128.png
sips -z 256 256 build/icon.png --out build/icon.iconset/icon_128x128@2x.png
sips -z 256 256 build/icon.png --out build/icon.iconset/icon_256x256.png
sips -z 512 512 build/icon.png --out build/icon.iconset/icon_256x256@2x.png
sips -z 512 512 build/icon.png --out build/icon.iconset/icon_512x512.png

# 转换为 ICNS
iconutil -c icns build/icon.iconset -o build/icon.icns
```

## 调试打包问题

### 常见问题

**1. Electron 下载失败**
```bash
# 设置镜像
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/

# 或使用本地缓存
npm run package  # --dir 模式使用已安装的 electron
```

**2. asar 打包错误**
```bash
# 检查 package.json 的 files 配置
# 确保 dist/ 和 dist-electron/ 存在
ls -la dist/ dist-electron/
```

**3. 模块加载错误**
```bash
# 检查 ESM/CommonJS 一致性
# tsconfig.electron.json: "module": "esnext"
# package.json: "type": "module"
```

**4. 图标缺失警告**
```bash
# 使用占位图标
# build/icon.png (1x1 透明 PNG)
base64 -d > build/icon.png << 'EOF'
iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg==
EOF
```

###  verbose 模式
```bash
# 详细日志
DEBUG=electron-builder npm run dist:linux
```

## CI/CD 集成

### GitHub Actions 示例

```yaml
name: Release
on:
  release:
    types: [published]

jobs:
  build:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    runs-on: ${{ matrix.os }}

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm

      - run: npm ci

      - name: Build Linux
        if: matrix.os == 'ubuntu-latest'
        run: npm run dist:linux

      - name: Build Windows
        if: matrix.os == 'windows-latest'
        run: npm run dist:win

      - name: Build macOS
        if: matrix.os == 'macos-latest'
        run: npm run dist:mac

      - uses: actions/upload-artifact@v4
        with:
          name: build-${{ matrix.os }}
          path: release/
```
