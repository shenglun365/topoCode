# 社区分析与下钻

> 关键词：社区、Louvain、下钻、面包屑、层级、回滚、社区命名、社区解释、社区分析、社区详情、内部社区、外部社区

## 概述

TopoCode 使用 Louvain 社区发现算法将项目的源文件自动分组为"社区"（模块）。社区是架构分析的基本单元。

页面路由：`/analysis` → 架构图 / 架构探索器。

## 社区层级结构

### 层级命名规则

| 层级 | 示例 ID | 说明 |
|------|---------|------|
| L0 | `L0-core` | 第一层社区，对应项目主要模块 |
| L1 | `L1-utils-parser` | L0 子社区（深入一层） |
| L2 | `L2-helpers-string` | L1 子社区（更细粒度） |
| Ln | ... | 可继续深入至叶子节点 |

**命名格式**：`L{层级}-{简要描述}-{可选子描述}`。

### 层级深度限制

社区层级深度取决于 Louvain 算法的递归分区，通常 2-4 层。越深的层级模块粒度越细，直到单个文件/符号。

## 社区类型

| 类型 | 说明 |
|------|------|
| `community`（内部社区） | 项目自己的代码形成的模块 |
| `external`（外部包） | 外部依赖包（如 npm 包、pip 包） |

## 下钻 (Drill-down)

### 什么是下钻

下钻是从当前层级进入子社区的过程。通过下钻，可以逐层深入理解项目内部的模块结构。

### 下钻方式

1. **双击力导向图中的节点** — 进入该社区的子结构
2. **点击表格视图中的行** — 进入该社区详情
3. **在面包屑中点击层级** — 跳转到对应层级
4. **架构探索器 (ArchitectureExplorer) 中点击展开** — 树状浏览子社区

### 面包屑导航

下钻后面包屑更新为新路径，例如：
```
项目名 > INCLUDE L0 > L0-utils > L1-string-helpers
```

- 点击面包屑中任意层级 → 跳转
- 点击回滚按钮 → 返回上一级

## 社区信息

### 社区属性

每个社区包含：

| 属性 | 说明 |
|------|------|
| communityId | 唯一标识符 |
| name | 社区名称（如已命名） |
| level | 层级（L0、L1、L2...） |
| parentId | 父社区ID |
| nodeCount | 成员节点数 |
| fileCount | 涉及文件数 |
| edgeCount | 内部边数 |
| qualityScore | 质量分数（0-1，越高表示模块内聚越好） |
| avgCoreness | 平均核心度（表示该社区被依赖的程度） |

### 质量分数 (qualityScore)

- 范围：0-1
- 含义：模块度（modularity）的近似值，衡量社区内部的紧密程度
- 高于 0.5：高质量模块，内部依赖紧密
- 0.2-0.5：中等质量
- 低于 0.2：低质量模块，内部松散，可能需要重构

### 核心度 (avgCoreness / maxCoreness)

- 表示社区被其他社区依赖的强度
- 核心度 ≥ 3：核心组件（被大量其他代码依赖）
- 核心度 0：独立模块或最底层模块

## 社区命名与分析

### AI 社区命名

TopoCode 支持使用 LLM 为社区生成中文名称和功能简介：

1. 选中一个或多个社区
2. 点击"批量分析"按钮
3. 启动 Agent 工作流 → 依次调用 LLM 分析每个社区
4. 返回：`{communityId, name, summary, mermaid, plantuml}`

### 社区详情查看

在力导向图中右键节点 → 查看详情 → 打开 SubDocViewer 展示社区详细信息（Markdown 格式）。

## 架构探索器 (ArchitectureExplorer)

位置：`/analysis` 页面 → 架构面板。

以树状结构展示社区层级：
```
依赖社区 (INCLUDE)
  ├─ L0-core (45 nodes)
  │   ├─ L1-core-impl (28 nodes)
  │   └─ L1-core-api (17 nodes)
  └─ L0-utils (30 nodes)
      └─ L1-utils-parser (12 nodes)

调用社区 (CALL)
  ├─ L0-service (35 nodes)
  └─ L0-handler (22 nodes)
```

## 常见问题

### Q: L0 社区很多（30+），如何快速了解？
1. 切换到表格视图，按节点数排序，先看最大的几个
2. 使用筛选面板 → 诊断面板 → 查看高核心度社区
3. 使用 AI 批量分析功能自动生成社区名称和摘要

### Q: 社区名称为什么是 ID 而不是中文？
社区名称默认使用自动生成的 ID。需要运行 AI 批量分析来为社区生成人类可读的名称。

### Q: 下钻到很深层级后如何快速回到顶层？
点击面包屑中最左侧的项目名称（或 L0），或多次点击回滚按钮。

### Q: 社区质量分数很低是什么意思？
表示该社区内部的成员之间依赖关系松散，可能是不相关的文件被算法归为一组。建议：
- 查看该社区的具体成员，确认是否合理
- 低质量社区可能需要人工审查代码结构
- 使用诊断面板快速定位所有低质量社区

### Q: 外部社区看不到？
切换到"外部"标签页查看外部依赖包。力导向图默认显示内部社区，通过标签切换查看外部社区。

### Q: 如何区分子社区和父社区？
- 父社区：L0-xxx、L1-xxx
- 子社区：parentId 指向父社区的社区
- 面包屑路径：L0 → L1 → L2 表示从顶层到第三层
