# 节点筛选面板

> 关键词：筛选面板、隐藏节点、分类筛选、诊断面板、搜索节点、高亮、过滤、显示节点、补全连接、显示关联节点

## 概述

节点筛选面板用于控制架构图中哪些节点可见。通过筛选面板可以隐藏不关心的社区，聚焦于特定类型的节点。

**打开方式**：点击顶栏漏斗图标 (FunnelIcon)，或使用搜索框右侧的筛选按钮。

**面板位置**：浮层面板，位于图区右侧。

## 面板三区域

### 区域一：分类筛选

使用固定阈值将节点分为不同类别，提供一键筛选。

#### 类型筛选

| 类型 | 说明 |
|------|------|
| 全部 | 显示所有社区 |
| 社区 | 仅显示内部社区（隐藏外部包） |
| 外部包 | 仅显示外部依赖包 |

#### 规模筛选

| 类别 | 阈值 | 说明 |
|------|------|------|
| 大型 (Large) | nodeCount > 30 | 节点数量超过30的大型社区 |
| 中型 (Mid) | 5 < nodeCount ≤ 30 | 中等规模的社区 |
| 小型 (Small) | nodeCount ≤ 5 | 节点数量不超过5的小社区 |

#### 质量筛选

| 类别 | 阈值 | 说明 |
|------|------|------|
| 高质量 (High) | qualityScore ≥ 0.5 | 模块内聚好的社区 |
| 中等 (Mid) | 0.2 < qualityScore < 0.5 | 中等质量 |
| 低质量 (Low) | qualityScore ≤ 0.2 | 模块内聚差的社区 |

#### 核心度筛选

| 类别 | 阈值 | 说明 |
|------|------|------|
| 核心 (Core) | avgCoreness ≥ 3 | 被大量其他代码依赖的核心模块 |
| 外围 (Peripheral) | avgCoreness < 3 | 依赖其他模块较多的非核心模块 |

#### 快捷操作

| 按钮 | 说明 |
|------|------|
| 隐藏外部包 | 一键隐藏所有外部依赖节点 |
| 只显示大型社区 | 仅显示 nodeCount > 30 的大型社区 |

### 区域二：节点列表

显示所有匹配搜索条件的节点，支持单独隐藏/显示。

**功能**：
- 搜索输入框 → 实时过滤列表（仅高亮匹配的节点，不改变 hiddenIds）
- 排序选项：按名称 / 入度(inDeg) / 出度(outDeg) / 节点数(count)
- 每个节点一行：checkbox 控制显示/隐藏 + 节点名称 + 标签 + 节点数
- 全选/取消全选

**重要**：搜索仅影响列表显示和高亮，不会自动隐藏不匹配的节点。

### 区域三：诊断面板

自动识别需要关注的节点并列出，支持一键操作。

| 诊断分类 | 判断条件 | 含义 |
|---------|---------|------|
| 低质量 | qualityScore < 0.3 | 内聚性差，可能需要重构 |
| 高核心 | avgCoreness ≥ 3 | 被大量依赖，改动影响大 |
| 孤立节点 | degree === 0 | 无任何连接边，可能是孤立模块 |
| 热依赖 | inDegree 排名前 20% | 被最多其他社区依赖 |

每个诊断结果显示社区名称和相关指标，以及操作按钮：
- **[显示]** — 取消隐藏该节点（如果已被隐藏）
- **[聚焦]** — 隐藏所有其他节点，只保留该节点可见

## 节点操作函数

| 函数 | 说明 |
|------|------|
| `hideNodes(ids)` | 隐藏指定节点 |
| `showNodes(ids)` | 显示指定节点（取消隐藏） |
| `focusNodes(ids)` | 隐藏所有节点，只显示指定节点 |
| `hideOthers(ids)` | 显示指定节点，隐藏其他所有节点 |
| `showAll()` | 取消所有隐藏 |

## 显示关联节点

在筛选面板中点击某个节点的"显示关联节点"按钮（原"补全连接"），将取消隐藏该节点的所有邻居节点。用于从被隐藏的图中恢复某个节点的上下文。

## 搜索框（顶栏）

顶栏搜索框的功能：
- 输入文本 → 高亮图中匹配的节点
- 同时过滤筛选面板节点列表中仅显示匹配项
- **不会隐藏/显示节点** — 只改变高亮状态

## 筛选 vs 高亮 的区别

| 操作 | 效果 | 对图的影响 |
|------|------|-----------|
| 筛选（隐藏节点）| 节点从图中消失 | 改变 hiddenIds，影响边显示和布局 |
| 高亮（搜索） | 节点高亮变色，其他变暗 | 仅改变视觉状态，不改变 hiddenIds |

筛选是高亮的"硬"版本——隐藏的节点完全不可见。高亮是"软"版本——所有节点都可见但匹配的更加显眼。

## 常见问题

### Q: 隐藏了节点后怎么恢复？
在筛选面板区域二的节点列表中，将隐藏节点的 checkbox 重新勾选，即可恢复显示。

### Q: 诊断面板显示"无孤立节点"，但图中明明有？
degree === 0 仅表示与**同层级其他社区**无边连接，不排除跨层级连接。这类节点在特定层级看是孤立的，但可能在上一层或下一层有连接。

### Q: 筛选面板的搜索和顶栏搜索有什么不同？
- 顶栏搜索 = 高亮匹配节点（视觉变化）
- 筛选面板搜索 = 过滤面板中的节点列表（不影响图）
- 两者联动：顶栏搜索的内容会同步到筛选面板

### Q: 分类筛选为什么用固定阈值而不是百分比？
固定阈值（large>30, quality≥0.5, core≥3）让用户建立直觉，知道自己在筛选什么。百分比阈值会随项目变化，不便于理解。
