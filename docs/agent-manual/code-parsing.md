# 代码解析与符号提取

> 关键词：代码解析、符号提取、AST、Tree-sitter、依赖分析、调用图、调用链、文件范围、排除目录、文件过滤、任务执行

## 概述

代码解析是 TopoCode 的核心能力之一，基于 Tree-sitter 进行 AST 解析，从源码中提取符号（函数、类、变量）并构建调用图和依赖图。

页面路由：`/code`。

## 分析任务创建

### 配置说明

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 范围(scope/路径) | 要分析的目录或文件子集 | `/src`, `/lib` |
| 文件扩展名 | 限定分析的编程语言 | `py`, `js`, `ts`, `go` |
| 排除目录 | 跳过不分析的目录 | `node_modules`, `__pycache__`, `.git`, `build`, `dist`, `vendor`, `test` |
| 报告类型 | 要生成的分析类型 | `dependency`(依赖), `callChain`(调用链) |

### 创建步骤

1. 进入 `/code` 页面（通过侧边栏或项目卡片进入）
2. 点击"创建任务"按钮
3. 选择文件范围（默认整个项目）
4. 选择文件扩展名（自动推荐项目主要语言）
5. 选择要跳过的目录
6. 选择报告类型
7. 提交任务

### 文件过滤高级说明

- 扩展名过滤：只分析匹配扩展名的文件，不匹配的直接跳过
- 排除目录：使用 glob 模式，如 `**/test/**` 排除所有测试目录
- 文件大小限制：超大文件（如 minified JS）可能被跳过以免拖慢分析

## 解析流程

### Tree-sitter AST 解析

TopoCode 使用 Tree-sitter（增量解析器）对源码进行抽象语法树分析，提取：

| 符号类型 | 说明 | 示例 |
|---------|------|------|
| function | 函数定义 | `def foo():`, `function bar() {}` |
| class | 类定义 | `class User:`, `class User {}` |
| method | 类方法 | `def __init__():` |
| variable | 全局变量/常量 | `API_URL = "..."` |
| import | 导入语句 | `import os`, `require('fs')` |

### 调用图 (Call Graph)

从符号中提取调用关系。例如：
```
main() → initConfig() → readYaml() → parse()
       → startServer() → listen()
```

### 依赖图 (Dependency Graph)

分析模块/文件间的依赖关系：
```
src/utils.ts → src/logger.ts
src/app.ts → src/utils.ts, src/router.ts
```

## 符号浏览

### 符号列表

任务完成后的左侧面板展示提取到的符号列表，可按文件或符号类型筛选。

### 符号详情

点击符号 → 显示详情卡片。显示项：
- 符号名称、类型
- 定义位置（文件路径、行号）
- 调用者列表（谁调用了该符号）
- 被调列表（该符号调用了谁）

### 边（Edge）解释

在图中选择一条边（调用或依赖关系），右键 → 查看详情 → 显示调用/依赖的源和目标。

## 任务管理

### 任务列表

`/code` 页面 → 任务列表，查看所有已创建任务及其状态。

### 查看任务详情

点击任务 → 查看任务进度、结果统计、符号列表。

### 重跑任务

任务失败或需要刷新：在任务列表中找到目标任务 → 重新运行。

## 解析性能

### 可解析的最大规模

取决于语言和目标机器：
- Python/JS/TS 项目：通常数万文件没问题
- C/C++ 大型项目：建议使用排除目录过滤第三方库

### 加速解析

1. 排除非核心目录（tests、docs、examples）
2. 限定分析扩展名
3. 仅选择依赖分析或调用链分析二者之一（而非两者都选）

## 常见问题

### Q: 解析报错 "tree-sitter grammar not found"
检查对应的 Tree-sitter 语法是否已安装。TopoCode 内置 11 种语言的语法，确认项目语言在支持列表中。

### Q: Python 解析错误 "could not parse"
确保 Python 代码语法正确。TopoCode 默认使用 Python 3.x 语法规则。

### Q: 任务状态一直 running
大型项目解析需要较长时间。查看进度提示。如长时间无进展，可能是某个文件解析卡住（超大文件或语法不兼容），尝试重跑任务并排除该文件。

### Q: 符号提取不完整
检查：
1. 文件扩展名是否在分析范围内
2. 是否包含了符号所在的文件目录
3. 是否有语法错误导致部分代码无法解析

### Q: 跨语言项目如何分析？
为每种语言创建单独的任务，选择对应的扩展名。
