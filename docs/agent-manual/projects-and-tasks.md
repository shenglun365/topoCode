# 项目管理与任务流程

> 关键词：导入项目、创建项目、任务创建、任务列表、删除项目、收藏项目、分组、批量管理、项目筛选、复合搜索

## 概述

TopoCode 以"项目"为分析单位，每个项目可创建多个"分析任务"。页面路由：`/home`。

右键侧边栏可切换导航标签：项目导入(Home)、代码解析(Code)、代码分析(Analysis)、知识库(Knowledge)、AI助手(Coder)、设置(User)。

## 导入项目

### 如何导入项目

点击页面右上角"导入项目"按钮 → 选择本地项目源码目录 → 系统自动扫描并导入。

导入成功后，系统会自动：
1. 扫描项目文件统计（各语言文件数量）
2. 识别主要编程语言
3. 自动创建一个分析任务（默认包含依赖分析和调用链分析）

### 支持的语言

11 种语言：C、C++、C#、Java、JavaScript、TypeScript、Python、Go、Rust、PHP、Swift。

也支持 Ruby、Kotlin、Dart、Scala、Lua 等额外语言的代码统计。

### 导入失败/重复导入

重复导入同一目录 → 弹窗提示"项目已存在"。如需要，可先删除已有项目再重新导入。

## 项目列表管理

### 筛选与搜索

**筛选模式**：全部 / 收藏（点击"全部"/"收藏"切换）

**分组筛选**：支持按项目分组过滤，下拉选择分组标签。

**复合搜索**：搜索框支持高级语法：

| 搜索语法 | 示例 | 说明 |
|---------|------|------|
| `name:xxx` | `name:topocode` | 按项目名称搜索 |
| `group:xxx` | `group:devtools` | 按分组搜索 |
| `language:xxx` | `language:python` | 按语言搜索 |
| 自由文本 | `cache utils` | 在名称/分组/路径中模糊匹配 |

示例组合：`group:backend language:go name:api` — 同时按分组、语言、名称过滤。

### 收藏项目

点击项目卡片的收藏图标（★）可将项目加入收藏，方便快速访问。再次点击取消收藏。

### 删除项目

右键项目卡片 → 删除项目；或在项目详情页中操作。删除后相关任务数据同步清除。

## 分析任务

### 任务创建

位置：项目详情页 / 任务面板 / "创建任务"按钮。

创建任务时的配置项：

| 配置项 | 说明 |
|--------|------|
| 范围(scopes) | 选择要分析的文件或目录，默认项目根目录 |
| 扩展名(extensions) | 限定分析的编程语言（如 py、js、ts） |
| 排除目录(excludeDirs) | 跳过不分析的目录（如 node_modules、.git、build） |
| 报告类型(reportTypes) | 选择报告类型：dependency(依赖分析)、callChain(调用链分析) |

### 任务类型

| 类型 | 说明 |
|------|------|
| `full` | 全量分析（推荐） |
| `incremental` | 增量分析（仅分析变更文件） |

### 任务生命周期

```
created → queued → running → completed
                           → error
                           → cancelled
```

- **queued**：已入队列，等待执行
- **running**：正在执行解析
- **completed**：解析成功
- **error**：解析失败（查看错误日志）
- **cancelled**：被手动取消

### 查看任务进度

任务列表中显示每个任务的状态图标：✓ 完成 / ● 运行中 / ○ 排队中 / ✗ 出错。

## 项目分组

### 创建分组

项目卡片 → 分组下拉 → "新建分组" → 输入分组名称。

### 管理分组

右键分组标签 → 重命名 / 删除。删除分组不会删除组内项目。

## 分页设置

项目列表支持分页，可在"设置"中调整每页数量（默认值在设置页 → 常规 → 分页大小）。

## 常见问题

### Q: 导入项目后看不到任务？
导入成功后系统会自动创建一个任务。如果被跳过，手动进入 `/code` 页面点击"创建任务"。

### Q: 修改代码后需要重新分析吗？
是的，需要创建新任务或增量任务来更新分析结果。

### Q: 如何删除多个项目？
当前不支持批量删除，需逐个操作。可使用搜索/筛选快速定位目标项目。
