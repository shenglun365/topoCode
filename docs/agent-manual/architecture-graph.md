# 架构图操作指南

> 关键词：力导向图、表格视图、热力图、结构图、可视化、全屏、缩放、图配置、齿轮面板、节点位置、保存位置、字体大小、排斥力

## 概述

架构图是 TopoCode 的核心可视化组件，展示项目的社区结构。支持三种视图模式，页面路由：`/analysis`。

工具栏布局（从左至右）：
```
[面包屑 社区路径] [搜索框] [筛选按钮] [力导向│表格│热力图] [⋮更多] [💾保存] [⚙图配置] [⛶全屏]
```

## 三种视图模式

### 力导向图 (Force)

**用途**：展示社区间的结构和关系，支持拖拽节点、调整布局。

**特点**：
- 节点大小表示社区规模（节点越多，圆越大）
- 边表示社区间的依赖或调用关系
- 支持拖拽节点调整位置
- 鼠标滚轮缩放，拖拽平移

**操作**：
- 拖拽节点：自由移动节点位置
- 单击节点：选中并高亮
- 双击节点：下钻到子社区
- 右键节点：查看社区详情

### 表格视图 (Table)

**用途**：列表查看社区的关键数据，支持排序和过滤。

**特点**：
- 表格列：社区名称、节点数、文件数、边数、质量分数、核心度、分析状态
- 支持按列排序（点击列头切换升序/降序）
- 搜索框过滤（按社区名称或ID）
- 分页显示（每页50条）
- 点击行 → 下钻到该社区

### 热力图 (Heatmap)

**用途**：按外部依赖热度展示外部包的使用密度。

**特点**：
- 每个单元格代表一个外部依赖包
- 颜色深浅表示使用频率（越深使用越多）
- 支持搜索过滤
- 点击单元格查看详情

## 图工具栏详解

### 视图切换标签

`[力导向│表格│热力图]` — 三个分段标签，点击切换当前视图。当前激活的标签高亮显示。

### ⋮ 更多菜单

点击 ⋮ 按钮展开下拉菜单：
- **重置视图**：将所有节点位置恢复到初始布局
- **导出架构**：将当前架构数据导出
- **对比架构**：打开版本对比面板（浮层）

### 💾 保存按钮

仅在节点位置发生变更后出现。点击保存当前所有节点位置。下次打开该社区时自动恢复保存的位置。

### ⚙ 图配置（齿轮面板）

点击齿轮图标打开配置面板：

| 配置项 | 适用视图 | 说明 |
|--------|---------|------|
| 字体大小 | 力导向图 | 调整节点标签字号的滑块 |
| 排斥力 | 力导向图 | 调整节点间排斥力的滑块（值越大节点越分散） |
| 跟随/独立 | 力导向图 | 跟随模式 = 跟随节点联动；独立模式 = 自由缩放拖拽 |
| 保存 (💾) | 力导向图 | 保存当前节点位置到服务端/本地 |
| 位置复原 | 力导向图 | 恢复到上次保存的节点位置 |
| 清除所有保存位置 | 力导向图 | 清除已保存的所有节点位置，恢复到默认布局 |

### ⛶ 全屏

点击 ⛶ 图标进入全屏模式。全屏模式下工具栏移到底部，点击对应的退出全屏按钮退出。

## 图操作

### 缩放与平移

**缩放**：
- 鼠标滚轮：缩放
- 画布左下角 +/- 按钮：步进缩放
- 全屏模式下缩放按钮调整到底部偏上位置

**平移**：
- 拖拽空白区域：平移画布
- 跟随模式时拖拽缩放跟随节点

### 节点交互

| 操作 | 效果 |
|------|------|
| 单击节点 | 选中并高亮，显示详情信息 |
| 双击节点 | 下钻到子社区（相当于进入社区内部） |
| 右键节点 | 打开上下文菜单（查看详情、打开文档等） |
| 拖拽节点 | 移动节点位置 |

### 面包屑导航

顶部面包屑显示当前所在层级路径。例如：
```
项目根 → L0-core → L1-utils → L2-helpers
```

点击面包屑中的任意层级 → 跳转到对应层级。
点击面包屑末尾的"回滚"按钮 → 返回上一层级。

## 边类型切换

架构图支持两种边（关系）类型：
- **INCLUDE（依赖）**：模块间的文件包含/引用关系
- **CALL（调用）**：函数/方法间的调用关系

通过 CommunityGraphView 的内外部标签页切换。

## 常见问题

### Q: 力导向图加载很慢或卡顿？
- 社区数量太多（超过100个节点）时，建议切换到表格视图或热力图
- 降低排斥力可减少力布局计算开销
- 缩小视野范围（只显示部分社区）可提升性能

### Q: 节点标签显示不全或重叠？
- 调整齿轮面板的字体大小
- 调整排斥力使节点分散
- 缩放到合适比例查看

### Q: 保存的位置不生效？
- 检查 💾 保存按钮是否已点击（位置显示蓝色时表示有未保存变更）
- 保存后该社区的下一次打开会恢复保存的位置
- "清除所有保存位置"可重置

### Q: 全屏模式下滑轮缩放异常？
全屏模式下浏览器的窗口行为可能影响缩放。使用画布上的 +/- 按钮替代。

### Q: 力导向图节点太小或太大？
节点大小和社区规模成正比。过滤掉大社区可让其他节点相对放大。调整排斥力可改变图布局密度。
