# 结构图改造 - 移除应用内结构图

日期: 2026-06-29

## 决策

移除应用内（Vue/Electron）的结构图功能，web 端 `viewer.html` 作为唯一的图入口。

文档保留在应用内（`SubDocViewer`），结构图（社区关系可视化）只通过浏览器访问。

### 不需要移植到 viewer.html 的功能

1. **选择模式 + 触发 agent 分析** — 不需要，tag 模式已支持选择
2. **节点/边 AI 解释按钮** — 不需要移植现有，待 web 端后续自主对话实现
3. **GraphCommandBus（AI 遥控图）** — 不具有实用性，移除
4. **子文档编辑** — 不需要，待 web 端后续整体改版
5. **版本对比** — 优先级低，本期不做
