## 一、核心概念

用户从任意层级出发，LLM 像导师一样从 **做什么** 和 **怎么做** 两个维度讲解系统，并且支持持续 **下钻** 到更细粒度。

```
[项目总览]                  做什么：源码架构分析工具
  └─ 怎么做：导入→解析→建图→社区发现→LLM分析→报告
      │
      ├─ [L0 社区 A]       做什么：处理用户认证与授权
      │   └─ 怎么做：JWT验证→RBAC权限检查→会话管理
      │      │
      │      ├─ [L1 子社区] 做什么：OAuth2.0 登录流程
      │      │   └─ 怎么做：redirect→callback→token exchange
      │      │      │
      │      │      ├─ [文件] auth/oauth_handler.py
      │      │      │   └─ 怎么做：处理 OAuth callback 路由...
      │      │      │      └─ [符号] exchange_code()
      │      │      │          └─ 怎么做：POST /token → 解析 response...
      │      │      └─ [文件] auth/token_utils.py ...
      │      │
      │      └─ [L1 子社区] 做什么：Session管理...
      │
      └─ [L0 社区 B]       做什么：核心业务逻辑...
```

## 三、需要扩展/新增的部分

### 3.1 后端：激活 AnalysisContext 并新增 "讲解" 服务

#### 新增数据模型 — `ExplainNode`

```
ExplainNode {
  level: 'project' | 'community' | 'file' | 'symbol'
  id: string
  label: string
  what: string                // LLM生成的"做什么"
  how: string                 // LLM生成的"怎么做"
  why?: string                // 可选的"为什么这么设计"
  children: ExplainNode[]     // 可下钻的子节点
  relatedNodes?: { label: string; level: string; id: string }[]  // LLM推荐的下一步
}
```

#### 新建 RPC 方法

| 方法 | 说明 |
|------|------|
| `analysis.explainNode({ taskId, level, id })` | 获取单层的 what/how/why |
| `analysis.explainSuggestNext({ taskId, level, id })` | 推荐可下钻/关联的节点 |
| `analysis.explainDrillDown({ taskId, parentLevel, parentId, childLevel })` | 获取子层列表 + AI 推荐 |
| `analysis.explainPath({ taskId, targetLevel, targetId })` | 从 root 到目标的路径摘要 |

#### 新增 Prompt 模板

| 模板 ID | 说明 |
|---------|------|
| `explain_what_how` | 对任意层级，同时输出"做什么"和"怎么做" |
| `explain_suggest_next` | 基于当前节点推荐探索方向 |
| `explain_path_summary` | 对整条探索路径做汇总 |

#### 复用 `AnalysisContext`

当前为死代码的 `AnalysisContext` 将被激活并集成到上述 RPC 方法中：

```python
ctx = AnalysisContext(task_id, db)
layer = ctx.get_community_layer(comm_id)     # 获取社区层数据
prompt = ctx.format_for_llm([project_layer, community_layer], "top-down")
# → LLM 生成 what/how
```

```
│  │                   │  └─────────────────────────────┘  │
└─────────────────────┴───────────────────────────────────┘
```

#### 关键交互

1. **探索树** — 左侧展示当前项目的层级结构树（类似现有 ArchitectureExplorer 但更结构化），当前讲解的节点高亮
2. **面包屑** — 显示从项目根到当前节点的路径，支持点击回退
3. **做什么/怎么做/为什么** — 三个 tab（或分节）展示 LLM 对当前节点的讲解
4. **推荐探索** — LLM 动态推荐下一步应看的子模块或关联模块，点击即跳转
5. **自由追问** — 底部对话输入框，针对当前模块提问（复用现有 ChatView）
6. **探索历史** — 侧边面板记录已看过的节点，支持回溯

#### 新增组件 & Store

| 内容 | 说明 |
|------|------|
| `components/explain/ExplainPanel.vue` | 主面板容器（左右分栏） |
| `components/explain/ExplainTree.vue` | 左边的层级探索树 |
| `components/explain/ExplainDetail.vue` | 右边的 LLM 讲解内容 |
| `components/explain/ExplainBreadcrumb.vue` | 面包屑导航 |
| `components/explain/ExplainHistory.vue` | 探索历史侧栏 |
| `stores/explain-store.ts` | 管理探索状态（当前路径、历史、已加载的说明缓存） |
