# 数据库结构说明

> 最后更新: 2026-05-12 | 4 类数据库、24 张表 | SQLite WAL 模式 | Tree-sitter 解析已集成

---

## 一、架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                      MultiDBManager                         │
│  LRU 缓存 (max=3) | WAL 模式 | busy_timeout=5000ms          │
│  synchronous=NORMAL | cache_size=10000 | 线程安全            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │  main.db     │  │ knowledge.db │  │ sessions.db  │      │
│  │  主库 10 表  │  │ 知识库 1 表  │  │ 会话库 2 表  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│                                                             │
│  ┌─────────────────────────────────────────────────┐        │
│  │  {project_id}.db  (每项目独立)                   │        │
│  │  项目库 11 表 (含 Tree-sitter 解析数据)          │        │
│  └─────────────────────────────────────────────────┘        │
│                                                             │
│  路径存储: 相对路径 (root_path 下)                           │
│  文件哈希: MD5 content_hash / hashcode                      │
│  数据目录: ~/.topoone (可配置 TOPOCODE_DB_DIR)               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 数据库文件位置

| 数据库 | 文件 | 路径 |
|--------|------|------|
| 主库 | `topoone.db` | `{userData}/topoone.db` |
| 知识库 | `knowledge.db` | `{userData}/knowledge.db` |
| 会话库 | `sessions.db` | `{userData}/sessions.db` |
| 项目库 | `{project_id}.db` | `{userData}/projects/{project_id}.db` |

> `userData` 路径: Linux `~/.topoone`, Windows `%APPDATA%\TopoOne`, macOS `~/Library/Application Support/TopoOne`

### 1.2 并发安全

- **WAL 模式**: 允许多读一写并发
- **busy_timeout=5000ms**: 写冲突时等待 5 秒
- **synchronous=NORMAL**: 性能与安全的平衡
- **MultiDBManager LRU**: 最多缓存 3 个打开的数据库连接
