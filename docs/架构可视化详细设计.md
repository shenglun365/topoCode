## 二、Mermaid 渲染引擎

### 2.1 架构

```
MermaidViewer.vue
  │
  ├─ useMermaidRender.ts (Composable)
  │     │
  │     ├─ renderManager.render('mermaid', data)
  │     │     │
  │     │     ├─ 缓存检查 → 命中则直接返回

  │     │           │
  │     │           └─ render-worker.ts (Web Worker)
  │     │                 ├─ mermaid.initialize({ theme, startOnLoad: false })
  │     │                 ├─ mermaid.render(id, diagram) → SVG string
  │     │                 └─ postMessage({ id, result: { svg } })
  │     │
  │     └─ 导出: { result, loading, error, progress }
  │
  └─ Template
        ├─ 编辑器模式: textarea (v-model code)
        ├─ 预览模式: <div v-html="svg"> (内嵌 SVG)
        └─ 工具栏: 复制/下载 SVG/PNG/切换主题
```

### 2.3 Worker 渲染流程

```typescript
// render-worker.ts
self.onmessage = async (e) => {
  const { id, type, data } = e.data

  if (type === 'mermaid') {
    const { diagram, theme } = data as MermaidData
    mermaid.initialize({ theme, startOnLoad: false })

    try {
      const svg = await mermaid.render(`m${Date.now()}`, diagram)
      postMessage({ id, result: { svg } })
    } catch (err) {
      postMessage({ id, error: err.message })
    }
  }
}
```

### 3.2 后端实现

```python
# backend/plantuml_service.py

# 配置 (从 settings 读取)
PLANTUML_CONFIG = {
    'mode': 'remote',          # 'remote' | 'local' | 'custom'
    'remote_url': 'https://www.plantuml.com/plantuml',  # 默认远程
    'custom_url': '',          # 用户自定义 API 地址
    'custom_token': '',        # 用户自定义 API 鉴权 Token
    'local_jar_path': '',      # 本地 plantuml.jar 路径
}

def render_plantuml(code: str, format: str = 'svg') -> dict:
    """
    1. URL 编码: deflate + base64 → PlantUML 编码
    2. 按配置模式渲染:
       - remote:   GET https://www.plantuml.com/plantuml/{format}/{encoded}
       - custom:   POST {custom_url}/render, Header: Authorization: Bearer {token}
       - local:    Java subprocess (plantuml.jar)
    3. 返回: {"data": "base64...", "format": "svg"}
    """
    encoded = encode_plantuml(code)

    if PLANTUML_CONFIG['mode'] == 'remote':
        return render_remote(PLANTUML_CONFIG['remote_url'], encoded, format)
    elif PLANTUML_CONFIG['mode'] == 'custom':
        return render_custom(
            PLANTUML_CONFIG['custom_url'],
            PLANTUML_CONFIG['custom_token'],
            encoded, format
        )
    elif PLANTUML_CONFIG['mode'] == 'local':
        return render_local(PLANTUML_CONFIG['local_jar_path'], encoded, format)

def render_custom(url: str, token: str, encoded: str, format: str) -> dict:
    """自定义 API 渲染 (带鉴权)"""
    import requests
    headers = {'Authorization': f'Bearer {token}'} if token else {}
    resp = requests.post(
        f"{url}/render",
        json={'code': encoded, 'format': format},
        headers=headers,
        timeout=30,
    )
    resp.raise_for_status()
    return resp.json()  # {"data": "base64...", "format": "svg"}

def test_plantuml() -> dict:
    """连接测试，返回 {"status": "ok", "mode": "remote"|"custom"|"local"}"""
```

## 四、TopoScript 自定义动画脚本

### 4.1 设计目标

TopoScript 是一种领域特定语言 (DSL)，用于描述架构动画。它定义了:
- **场景**: 节点、边、布局
- **动画序列**: 入场、流动、高亮、变换
- **交互**: 点击、悬停、拖拽

渲染后端可选 D3.js (SVG) 或 Pixi.js (WebGL Canvas)。

### 4.2 语言规范

### 4.4 TopoParser — 自定义 AST 解析器

TopoScript 采用自定义词法分析器 + 递归下降语法分析器，不依赖 eval/iframe，安全性最高。

#### 4.4.1 词法分析 (Tokenizer)

```typescript
// src/services/topo-tokenizer.ts

type TokenType =
  | 'KEYWORD'      // topo, scene, node, edge, sequence, step, interaction
  | 'IDENT'        // 标识符 (gateway, auth, fade-scale)
  | 'STRING'       // "request flow", "#4A90D9"
  | 'NUMBER'       // 1200, 0.5, -10
  | 'LBRACE'       // {
  | 'RBRACE'       // }
  | 'LBRACKET'     // [
  | 'RBRACKET'     // ]
  | 'LPAREN'       // (
  | 'RPAREN'       // )
  | 'COMMA'        // ,
  | 'COLON'        // :
  | 'ARROW'        // →
  | 'DOT'          // .
  | 'EOF'

interface Token {
  type: TokenType
  value: string
  line: number
  column: number
}

class Tokenizer {
  private source: string
  private pos = 0

  constructor(source: string) {
    this.source = source
  }

  *tokenize(): Generator<Token> {
    while (this.pos < this.source.length) {
      // 跳过空白/注释
      if (this.skipWhitespace()) continue
      if (this.skipComment()) continue

      const ch = this.source[this.pos]

      // 字符串
      if (ch === '"' || ch === "'" || ch === '`') {
        yield this.readString()
        continue
      }

      // 数字
      if (/\d/.test(ch) || (ch === '-' && /\d/.test(this.source[this.pos + 1]))) {
        yield this.readNumber()
        continue
      }

      // 标识符 / 关键字
      if (/[a-zA-Z_$]/.test(ch)) {
        const word = this.readWord()
        if (KEYWORDS.has(word)) {
          yield { type: 'KEYWORD', value: word, line: this.line, column: this.column }
        } else {
          yield { type: 'IDENT', value: word, line: this.line, column: this.column }
        }
        continue
      }

      // 符号
      const symbol = SYMBOLS.get(ch)
      if (symbol) {
        yield { type: symbol, value: ch, line: this.line, column: this.column }
        this.pos++
        continue
      }

      // 箭头 →
      if (ch === '→' || (ch === '-' && this.source[this.pos + 1] === '>')) {
        yield { type: 'ARROW', value: '→', line: this.line, column: this.column }
        this.pos += ch === '→' ? 1 : 2
        continue
      }

      throw new Error(`Unexpected character '${ch}' at ${this.line}:${this.column}`)
    }
    yield { type: 'EOF', value: '', line: this.line, column: this.column }
  }

  private skipWhitespace(): boolean { /* ... */ }
  private skipComment(): boolean { /* // ... 和 /* ... */ }
  private readString(): Token { /* ... */ }
  private readNumber(): Token { /* ... */ }
  private readWord(): string { /* ... */ }
}

const KEYWORDS = new Set([
  'topo', 'scene', 'node', 'edge', 'sequence', 'step',
  'interaction', 'click', 'hover', 'drag',
  'true', 'false', 'null',
])

const SYMBOLS = new Map([
  ['{', 'LBRACE'], ['}', 'RBRACE'],
  ['[', 'LBRACKET'], [']', 'RBRACKET'],
  ['(', 'LPAREN'], [')', 'RPAREN'],
  [',', 'COMMA'], [':', 'COLON'], ['.', 'DOT'],
])
```

interface InteractionConfig {
  target: string
  events: Record<string, string>  // event → action expression
}

interface FlowParticleConfig {
  color?: string
  size?: number
  speed?: number
}

class TopoParser {
  private tokens: Token[]
  private pos = 0

  constructor(source: string) {
    const tokenizer = new Tokenizer(source)
    this.tokens = Array.from(tokenizer.tokenize())
  }

  parse(): TopoAST {
    const ast: TopoAST = {
      scene: { layout: 'force-directed', width: 1200, height: 800, renderer: 'd3' },
      nodes: [],
      edges: [],
      sequences: [],
      interactions: [],
    }

    while (this.current().type !== 'EOF') {
      // topo.scene({ ... })
      if (this.match('KEYWORD', 'topo')) {
        this.expect('DOT')
        const method = this.expect('KEYWORD').value

        this.expect('LPAREN')
        const arg = this.parseObject()
        this.expect('RPAREN')

        switch (method) {
          case 'scene':
            ast.scene = { ...ast.scene, ...arg }
            break
          case 'node':
            ast.nodes.push(arg as TopoNode)
            break
          case 'edge':
            ast.edges.push(arg as TopoEdge)
            break
          case 'sequence':
            ast.sequences.push(arg as AnimationSequence)
            break
          case 'interaction':
            ast.interactions.push(arg as InteractionConfig)
            break
          default:
            throw new Error(`Unknown topo method: ${method}`)
        }
      } else {
        this.advance()  // skip unknown
      }
    }

    return ast
  }

  private parseObject(): Record<string, any> {
    this.expect('LBRACE')
    const obj: Record<string, any> = {}

    while (this.current().type !== 'RBRACE' && this.current().type !== 'EOF') {
      const key = this.parseKey()
      this.expect('COLON')
      obj[key] = this.parseValue()

      if (this.current().type === 'COMMA') {
        this.advance()
      }
    }

    this.expect('RBRACE')
    return obj
  }

  private parseKey(): string {
    const tok = this.current()
    if (tok.type === 'IDENT' || tok.type === 'KEYWORD') {
      this.advance()
      return tok.value
    }
    if (tok.type === 'STRING') {
      this.advance()
      return tok.value
    }
    throw new Error(`Expected key, got ${tok.type}`)
  }

  private parseValue(): any {
    const tok = this.current()

    switch (tok.type) {
      case 'STRING':
        this.advance()
        return tok.value
      case 'NUMBER':
        this.advance()
        return parseFloat(tok.value)
      case 'KEYWORD':
        this.advance()
        if (tok.value === 'true') return true
        if (tok.value === 'false') return false
        if (tok.value === 'null') return null
        return tok.value  // 标识符关键字当作字符串
      case 'IDENT':
        this.advance()
        return tok.value
      case 'LBRACE':
        return this.parseObject()
      case 'LBRACKET':
        return this.parseArray()
      default:
        throw new Error(`Unexpected token: ${tok.type} (${tok.value})`)
    }
  }

  private parseArray(): any[] {
    this.expect('LBRACKET')
    const arr: any[] = []

    while (this.current().type !== 'RBRACKET' && this.current().type !== 'EOF') {
      arr.push(this.parseValue())
      if (this.current().type === 'COMMA') this.advance()
    }

    this.expect('RBRACKET')
    return arr
  }

  private current(): Token { return this.tokens[this.pos] }
  private advance(): Token { return this.tokens[this.pos++] }
  private match(type: TokenType, value?: string): boolean {
    return this.current().type === type && (value === undefined || this.current().value === value)
  }
  private expect(type: TokenType, value?: string): Token {
    const tok = this.current()
    if (tok.type !== type || (value !== undefined && tok.value !== value)) {
      throw new Error(`Expected ${type}(${value ?? ''}) at ${tok.line}:${tok.column}, got ${tok.type}(${tok.value})`)
    }
    return this.advance()
  }
}
```

    // 3. 渲染节点
    this.renderNodes(ast.nodes, positions)

      case 'grid':
        return this.gridLayout(ast)
      case 'circular':
        return this.circularLayout(ast)
      default:
        return this.forceLayout(ast)
    }
  }

        case 'circle':

            .attr('r', 25)
            .attr('fill', style.fill || '#4A90D9')
            .attr('stroke', style.stroke || '#2C5F8D')
            .attr('stroke-width', 2)

        .attr('text-anchor', 'middle')
        .attr('dy', '0.35em')
        .attr('fill', '#fff')

class PixiRenderer {
  private app: PIXI.Application
  private nodeContainer: PIXI.Container
  private edgeContainer: PIXI.Container

  constructor(container: HTMLElement, config: SceneConfig) {

      width: config.width,
      height: config.height,
      antialias: true,
      resolution: window.devicePixelRatio || 1,
      autoDensity: true,
    })
    container.appendChild(this.app.view)

    this.edgeContainer = new PIXI.Container()
    this.nodeContainer = new PIXI.Container()
    this.particleContainer = new PIXI.Container()

    this.app.stage.addChild(this.edgeContainer)
    this.app.stage.addChild(this.nodeContainer)
    this.app.stage.addChild(this.particleContainer)
  }

  render(ast: TopoAST): void {
    const positions = this.computeLayout(ast)

    // 渲染边 (Graphics 线条)
    ast.edges.forEach(edge => {
      const src = positions.get(edge.source)
      const tgt = positions.get(edge.target)
      if (!src || !tgt) return

      const graphics = new PIXI.Graphics()
      graphics.lineStyle(edge.style?.width || 2, hexToNumber(edge.style?.color || '#4A90D9'))
      graphics.moveTo(src.x, src.y)
      graphics.lineTo(tgt.x, tgt.y)
      this.edgeContainer.addChild(graphics)
    })

    // 渲染节点 (带发光效果)
    ast.nodes.forEach(node => {
      const pos = positions.get(node.id)
      if (!pos) return

      const container = new PIXI.Container()
      container.x = pos.x
      container.y = pos.y

      // 发光光晕
      const glow = new PIXI.Graphics()
      glow.beginFill(hexToNumber(node.style?.fill || '#4A90D9'), 0.3)
      glow.drawCircle(0, 0, 35)
      glow.endFill()
      container.addChild(glow)

      // 主体
      const body = new PIXI.Graphics()
      body.beginFill(hexToNumber(node.style?.fill || '#4A90D9'))
      body.lineStyle(2, hexToNumber(node.style?.stroke || '#2C5F8D'))
      body.drawRoundedRect(-60, -20, 120, 40, node.style?.radius || 4)
      body.endFill()
      container.addChild(body)

      // 文字
      const text = new PIXI.Text(node.label, {
        fontSize: node.style?.fontSize || 12,
        fill: 0xffffff,
        align: 'center',
      })
      text.anchor.set(0.5)
      container.addChild(text)

      this.nodeContainer.addChild(container)
    })
  }

  // 流动粒子动画
  animateFlow(path: string[], positions: Map<string, { x: number; y: number }>, config: FlowConfig): void {
    const particle = new PIXI.Graphics()
    particle.beginFill(hexToNumber(config.color || '#FF6B6B'))
    particle.drawCircle(0, 0, config.size || 6)
    particle.endFill()
    this.particleContainer.addChild(particle)

    // 沿路径移动
    const points = path.map(id => positions.get(id)).filter(Boolean)
    let i = 0
    this.app.ticker.add(() => {
      if (i < points.length - 1) {
        const from = points[i]
        const to = points[i + 1]
        const t = (Date.now() % config.duration) / config.duration
        particle.x = from.x + (to.x - from.x) * t
        particle.y = from.y + (to.y - from.y) * t
      }
    })
  }
}

// src/services/topo-animator.ts

interface AnimationStep {
  type: 'enter' | 'exit' | 'draw-edge' | 'flow' | 'highlight' | 'reset' | 'wait' | 'morph'
  targets?: string[]
  path?: string[]
  effect?: string
  style?: any
  particle?: FlowParticleConfig
  duration: number
  delay?: number
}

interface AnimationSequence {
  name: string
  autoPlay?: boolean
  loop?: boolean
  steps: AnimationStep[]
}

class TopoAnimator {
  private renderer: D3Renderer | PixiRenderer
  private currentSequence: AnimationSequence | null = null
  private playing = false
  private currentStep = 0
  private timers: ReturnType<typeof setTimeout>[] = []
  private rafId: number | null = null

  constructor(renderer: D3Renderer | PixiRenderer) {
    this.renderer = renderer
  }

  play(sequence: AnimationSequence): void {
    this.currentSequence = sequence
    this.playing = true
    this.currentStep = 0
    this.executeStep(0)
  }

  private executeStep(index: number): void {
    if (!this.playing || !this.currentSequence) return
    if (index >= this.currentSequence.steps.length) {
      if (this.currentSequence.loop) {
        this.currentStep = 0
        this.executeStep(0)
      }
      return
    }

    this.currentStep = index
    const step = this.currentSequence.steps[index]

    if (step.delay) {
      const timer = setTimeout(() => this.runStep(step), step.delay)
      this.timers.push(timer)
      return
    }

    this.runStep(step)
  }

  private runStep(step: AnimationStep): void {
    switch (step.type) {
      case 'enter':
        this.animateEnter(step.targets!, step.effect || 'fade-scale', step.duration)
        break
      case 'draw-edge':
        this.animateDrawEdge(step.targets!, step.duration)
        break
      case 'flow':
        this.animateFlow(step.path!, step.particle, step.duration)
        break
      case 'highlight':
        this.animateHighlight(step.targets!, step.style, step.duration)
        break
      case 'reset':
        this.resetHighlight(step.targets!)
        break
      case 'wait':
        const timer = setTimeout(() => this.executeStep(this.currentStep + 1), step.duration)
        this.timers.push(timer)
        return
    }

    // 当前步骤完成后，执行下一步
    const timer = setTimeout(() => this.executeStep(this.currentStep + 1), step.duration)
    this.timers.push(timer)
  }

  private animateEnter(targets: string[], effect: string, duration: number): void {
    // D3: d3.transition().style('opacity', 1).attr('transform', 'scale(1)')
    // Pixi: ticker-based alpha/scale interpolation
  }

  private animateDrawEdge(targets: string[], duration: number): void {

  private animateFlow(path: string[], particle: FlowParticleConfig, duration: number): void {

    this.timers = []
    if (this.rafId) cancelAnimationFrame(this.rafId)

            code: block.code, format: 'svg',
          })
          el.innerHTML = `<img src="data:image/svg+xml;base64,${(plantumlResult as any).data}" />`
          break

        case 'toposcript':
          // 嵌入 TopoStage 组件
          el.innerHTML = `<topo-stage
            :script="${JSON.stringify(block.code)}"
            :auto-play="true"
            style="width:100%; height:400px;"
          ></topo-stage>`
          await nextTick()
          break
      }
    } catch (e: any) {
      el.innerHTML = `<pre class="chart-error">${e.message}</pre>`
    }
  }
}
```

### 8.2 决策补充说明

#### D8: TopoScript 热更新

```typescript
// TopoStage.vue
watch(() => props.script, () => {
  if (debounceTimer) clearTimeout(debounceTimer)
  debounceTimer = setTimeout(() => {
    loadScript()  // 重新解析 + 渲染
  }, 1000)  // 1000ms 防抖
}, { immediate: false })
```

用户在编辑器中输入 TopoScript，停止输入 1 秒后自动重渲染。避免频繁解析导致性能问题。

#### D10: TopoScript 语法扩展（外部引擎）

当前 TopoScript 为纯声明式 DSL（`topo.node/edge/sequence`），不支持变量、函数、条件语句。

**扩展方案**: 外部引擎实现后，通过插件机制引入：

```typescript
// 插件接口
interface TopoScriptPlugin {
  name: string
  version: string
  // 扩展解析器：在 Tokenizer/Parser 前后注入自定义逻辑
  extendParser?(parser: TopoParser): TopoParser
  // 扩展运行时：提供变量/函数/条件语句的执行环境
  provideRuntime?(): TopoRuntime
  // 扩展渲染器：注册新的节点类型/动画效果
  extendRenderer?(renderer: D3Renderer | PixiRenderer): void
}

// 加载外部引擎
async function loadPlugin(url: string): Promise<TopoScriptPlugin> {
  const module = await import(/* webpackIgnore: true */ url)
  return module.default as TopoScriptPlugin
}

// 使用示例
const plugin = await loadPlugin('./plugins/toposcript-logic-engine.js')
topoEngine.registerPlugin(plugin)
```

**外部引擎职责**:
- 提供变量作用域管理 (`let x = 10`)
- 提供函数定义和调用 (`func drawNode(id) { ... }`)
- 提供条件语句 (`if (status == 'error') { ... }`)
- 提供循环 (`for (let i = 0; i < nodes.length; i++) { ... }`)

当前项目只负责：定义插件接口、加载外部引擎、将扩展后的 AST 传递给渲染器。

#### D11: 动画帧率控制

```typescript
// PixiRenderer
constructor(container: HTMLElement, config: SceneConfig) {
  this.app = new PIXI.Application({
    // ...
  })

  // 默认 10 FPS，上限 60 FPS
  const targetFps = config.fps || 10
  this.app.ticker.speed = targetFps / 60  // Pixi 默认 60fps，通过 speed 缩放
  this.app.ticker.maxFPS = 60
}

// D3Renderer — CSS transition 不受帧率限制
// transition: transform 0.3s ease-out
// 浏览器自动以 60fps 渲染，无需手动控制
```

| 渲染器 | 帧率控制方式 | 默认值 | 上限 |
|--------|------------|--------|------|
| D3 SVG | CSS `transition` / `animation` | 浏览器默认 (60fps) | 60fps |
| Pixi.js | `app.ticker.speed` + `maxFPS` | 10fps | 60fps |

主要展示架构和算法逻辑，10 FPS 已足够流畅，无需过高刷新率。
