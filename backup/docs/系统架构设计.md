# TopoOne 系统架构设计

> 基于当前原型功能汇总，规划组件级系统架构。

---

## 一、系统定位

**TopoOne** — 源码架构分析与可视化教学工具

以「代码解析 → 知识沉淀 → AI 调度」为主线，为开发者提供从源码理解到设计落地的闭环工具链。

| 模块 | 定位 | 差异化 |
|------|------|--------|
| 模块一: 项目导入与代码分析 | 源码解析引擎 | 结构化 AST + 调用链 + 依赖图 + 数据流 |
| 模块二: 知识库 | 私有知识中枢 | 四维分类 + 知识图谱 + 动画脚本嵌入 |
| 模块三: AI 助手 (Architect Agent) | 架构师智能体 | 上下文投喂 + Spec 生成 + CLI Agent 调度 |
| 模块四: 设置与配置 | 全局配置中心 | 模型/Agent/SKILL/插件管理 |

### 3.3 核心组件详细设计

#### 3.3.1 UI Shell 组件

| 组件 | 职责 | 通信 |
|------|------|------|
| **TopBar** | 菜单(文件/编辑/查看/工具/帮助) + 面板切换 + 主题切换 | 菜单动作 → 全局事件总线 |
| **ActivityBar** | 5 个模块导航入口，激活态指示 | 点击 → `switchPage(pageName)` |
| **LeftPanel** | 页面上下文列表，由模板动态注入 | `updateLeftPanel(page)` 注入内容 |
| **RightPanel** | 页面详情/过滤器/上下文，由模板动态注入 | `updateRightPanel(page)` 注入内容 |
| **StatusBar** | 语言/AST 状态/Git 分支/AI 模型/编码/缩放 | 各 Service 推送状态更新 |

## 五、技术选型

### 5.1 前端 (当前原型 → 正式)

| 层级 | 当前原型 | 正式方案 |
|------|----------|----------|
| 框架 | 原生 HTML/CSS/JS | **Electron + Vue 3 + TypeScript** |
| 样式 | Catppuccin CSS 变量 | **Tailwind(为主) + CSS 变量（辅助）** |

| 代码编辑 | 静态 HTML | **Monaco Editor** |
| Markdown | 静态渲染 | **Markdown-it + 自定义渲染器** |
| 状态管理 | 全局变量 | **Pinia** |
| 路由 | 自定义 switchPage | **Vue Router** |

### 5.2 后端服务

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 主进程 | **Python 3.12 + FastAPI** | 解析引擎 + API 服务 |
| AST 解析 | **Tree-sitter** | 多语言支持 (Py/Go/JS/Java) |
| 知识图谱 | **NetworkX ** | 轻量用 NetworkX，大规模用 Neo4j |
| RAG 检索 | **ChromaDB / FAISS** | 向量检索知识库 |
| 文件监听 | **watchdog** | 代码变更自动触发分析 |
| 任务队列 | **Celery / asyncio** | 分析任务异步执行 |

### 5.3 AI 服务

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 本地模型 | **LM-STUDIO**、**Ollama** | qwen3.5-9B Q4量化以上 |
| 云端模型 | **OpenAI API** |  国内主流模型均可 |
| 模型路由 | **轻量级路由 + LangGraph 核心** | 按任务类型分发 |
| Spec 生成 | Prompt 模板 + LLM | 结构化输出 |
| CLI 调度 | **subprocess / ChildProcess** | 调用 qwen-code/cline |

### 5.4 数据存储

|----------|----------|------|
| 项目元数据 | **SQLite** | 轻量本地数据库 |

## 八、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| Agent 定位 | 架构师(不写代码) | 避免与 qwen-code/cline 同质化 |
| 代码生成 | 调度外部 CLI Agent | 利用成熟工具，专注上下文投喂 |
| 校验策略 | 默认=编译+测试 | 严格校验通过 SKILL 拓展 |
| 分类系统 | 四维平行标签 | 替代树形结构，多维度检索 |
| 知识存储 | SQLite + 文件 | 轻量本地优先，可扩展 Neo4j |
| 图谱渲染 | D3.js | 灵活定制，社区成熟 |
| 前端框架 | Electron + Vue 3 | 桌面端 + 响应式 + TypeScript |
| 后端框架 | FastAPI | Python 生态 + 异步 + 自动文档 |
