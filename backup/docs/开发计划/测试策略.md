## 2. 前端测试 (Vitest)

### 2.1 测试框架

```
Vitest + @vue/test-utils + jsdom
```

### 2.2 测试范围

| 测试对象 | 工具 | 覆盖目标 |
|----------|------|----------|
| Pinia Stores | Vitest | 所有 action/getter 逻辑，边界条件 |
| Vue Composables | Vitest + @vue/test-utils | 所有可组合函数 |

## 3. 后端测试 (pytest)

### 3.1 测试框架

```
pytest + pytest-asyncio + httpx (AsyncClient) + pytest-cov
```

### 3.2 测试范围

| 测试对象 | 工具 | 覆盖目标 |
|----------|------|----------|
| API 端点 | pytest + httpx.AsyncClient | 所有 CRUD 端点，状态码，响应格式 |
| Service 层 | pytest + Mock | 业务逻辑，错误处理，边界条件 |
| 数据模型 | pytest | 验证器，关系，级联 |
| Tree-sitter 集成 | pytest | 各语言解析正确性 |

### 3.4 关键测试场景

```python
# API 响应格式验证
async def test_unified_response_format(async_client):
    resp = await async_client.get("/api/v1/projects")
    assert resp.status_code == 200
    body = resp.json()
    assert "code" in body
    assert "message" in body
    assert "data" in body
    assert body["code"] == 0

# 分析任务生命周期
async def test_analysis_task_lifecycle(async_client, sample_project):
    # 创建任务
    resp = await async_client.post("/api/v1/tasks", json={...})
    task_id = resp.json()["data"]["id"]

    # 查询任务状态
    resp = await async_client.get(f"/api/v1/tasks/{task_id}")
    assert resp.json()["data"]["status"] == "pending"

    # 获取报告 (需 mock Tree-sitter)
    resp = await async_client.get(f"/api/v1/tasks/{task_id}/report")
    assert resp.json()["data"] is not None
```

## 5. CI 集成

```yaml
# .github/workflows/test.yml
name: Test

on: [push, pull_request]

jobs:
  frontend-unit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run test:unit

  backend-unit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.12' }
      - run: pip install -r requirements-dev.txt
      - run: pytest --cov

  e2e:
    runs-on: ubuntu-latest
    needs: [frontend-unit, backend-unit]
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npx playwright install --with-deps
      - run: npm run test:e2e
```
