# 开发环境对齐指南

## 当前状态

- **Phase 1**: UI Shell 脚手架已完成
- **技术栈**: Electron + Vue 3.5 + TypeScript + Vite + Pinia + Tailwind CSS
- **主题**: Catppuccin Mocha (暗色/亮色)

## 项目结构

```

├── electron/           # Electron 主进程
│   ├── main.ts        # 主进程入口
│   └── preload.ts     # 预加载脚本
├── src/
│   ├── components/    # 组件
│   │   └── shell/     # Phase 1: UI Shell 组件
│   │       ├── AppShell.vue
│   │       ├── TopBar.vue

│   │       ├── RightPanel.vue

│   ├── pages/         # 页面 (Phase 2-5)
│   ├── stores/        # Pinia Store
│   │   ├── navigation.ts
│   │   ├── panel.ts
│   │   ├── theme.ts
│   │   └── status.ts
│   ├── router/        # Vue Router

```

## 开发命令

```bash
# 安装依赖
npm install

# 启动开发服务器 (Vite + Electron)
npm run dev

# 仅启动 Vite (浏览器调试)
npm run dev:vite

# 类型检查
npm run type-check

# 代码格式化
npm run lint

# 构建
npm run build
```
