# 部署与打包方案

> Electron 应用打包、自动更新、跨平台支持、CI/CD 流水线

---

## 1. 打包工具选型

| 工具 | 用途 |
|------|------|
| **electron-builder** | Electron 应用打包 (Windows/macOS/Linux) |
| **PyInstaller** 或嵌入 | Python 后端分发 (可选：打包为独立可执行文件) |
| **NSIS** (Windows) / **DMG** (macOS) / **AppImage** (Linux) | 安装包格式 |

---

## 2. 打包策略

### 2.1 方案 A: 分离部署 (推荐开发阶段)

```
安装包内含:
  - Electron 应用 (前端)
  - Node.js 运行时 (Electron 自带)
  - Python 脚本 (源码形式)

用户需自行安装:
  - Python 3.12+
  - pip install -r requirements.txt
```

**优点**: 包体积小 (~100MB)，Python 依赖可由用户管理。
**缺点**: 需要用户安装 Python 环境。

### 2.2 方案 B: 嵌入式部署 (推荐发布阶段)

```
安装包内含:
  - Electron 应用 (前端)
  - Python 嵌入式运行时 (使用 PyInstaller 打包为单文件)
  - 所有 Python 依赖

用户无需安装任何额外环境。
```

**优点**: 开箱即用。
**缺点**: 包体积大 (~300-500MB)，需处理 Python 版本兼容。

## 3. electron-builder 配置

```json5
// electron-builder.yml (或 package.json "build" 字段)
{
  appId: "com.topocode.topone",
  productName: "TopoOne",
  directories: {
    output: "dist-electron"
  },
  files: [
    "dist/**/*",           // Vite 构建输出
    "src/main/**/*",
    "src/preload/**/*",
    "backend/**/*",        // Python 后端
    "requirements.txt"
  ],
  extraResources: [
    { from: "backend/", to: "backend/" }
  ],
  mac: {
    target: ["dmg", "zip"],
    icon: "assets/icon.icns",
    category: "public.app-category.developer-tools"
  },
  win: {
    target: ["nsis"],
    icon: "assets/icon.ico"
  },
  linux: {
    target: ["AppImage", "deb"],
    icon: "assets/icon.png",
    category: "Development"
  },
  nsis: {
    oneClick: false,
    allowToChangeInstallationDirectory: true
  },
  publish: {
    provider: "github",
    owner: "your-org",
    repo: "topoOne-ui"
  }
}
```

## 4. Python 后端嵌入方案

```
┌─────────────────────────────────────────────────────┐
│  构建流程 (CI)                                      │
│                                                     │
│  1. pip install -r requirements.txt                 │
│  2. pyinstaller --onefile --name topoOne-backend \  │
│         --add-data "config:config"                  │
│         main.py                                     │
│  3. 输出: dist/topoOne-backend (单文件可执行)       │
│                                                     │
│  运行时 (Main Process)                              │
│                                                     │
│  const backendPath = path.join(                     │
│    process.resourcesPath,                           │
│    'backend',                                       │
│    'topoOne-backend' + (win ? '.exe' : '')          │
│  );                                                 │
│  spawn(backendPath, ['--port', port]);              │
└─────────────────────────────────────────────────────┘
```

## 5. 自动更新

使用 electron-updater + GitHub Releases:

```typescript
// src/main/updater.ts
import { autoUpdater } from 'electron-updater';

autoUpdater.autoDownload = false;
autoUpdater.autoInstallOnAppQuit = true;

autoUpdater.on('update-available', (info) => {
  // 通知 Renderer: 有新版本可用
  mainWindow.webContents.send('updater:available', info);
});

// Renderer 调用 check
ipcMain.handle('updater:check', async () => {
  await autoUpdater.checkForUpdates();
});
```

更新流程:
```
GitHub Release → electron-updater 检测 → 用户确认 → 下载 → 安装 → 重启
```

## 6. CI/CD 流水线

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags: ['v*']

jobs:
  build:
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest]

    runs-on: ${{ matrix.os }}

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with: { node-version: '20' }

      - uses: actions/setup-python@v5
        with: { python-version: '3.12' }

      - name: Install deps
        run: |
          npm ci
          pip install -r requirements.txt pyinstaller

      - name: Build Python backend
        run: pyinstaller --onefile backend/main.py -n topoOne-backend

      - name: Build Electron
        run: npm run build && npx electron-builder --publish always

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: topoOne-${{ matrix.os }}
          path: dist-electron/*
```

## 7. 版本策略

```
版本号: MAJOR.MINOR.PATCH

MAJOR: 架构大变更 / 不兼容的 API 变更
MINOR: 新 Phase 完成 / 新模块上线
PATCH: Bug 修复 / 小改进

示例:
  v0.1.0  → Phase 1 完成
  v0.2.0  → Phase 2 完成
  v0.5.0  → 全部 Phase 完成
  v1.0.0  → 正式发布
```

## 8. 分发渠道

| 阶段 | 渠道 | 说明 |
|------|------|------|
| 开发 | `npm run dev` | Vite dev server + Electron |
| 内测 | GitHub Releases (pre-release) | 邀请测试用户 |
| 公测 | GitHub Releases (release) | 公开下载 |
| 稳定版 | 官网 + GitHub + 包管理器 | Homebrew / Snap / Winget |
