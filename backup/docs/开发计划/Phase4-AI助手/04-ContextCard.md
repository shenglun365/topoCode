# ContextCard 组件设计

> 上下文检索卡片，展示 AI 检索到的相关知识

---

## 1. 组件职责

- 展示检索到的知识文档
- 提供文档预览入口
- 展示相关度评分

## 2. 布局结构

```
┌─────────────────────────────────────────┐
│ 📄 JWT认证规范              [相关度 95%] │
│                                         │
│ JWT Token 的生成、验证、刷新流程规范...  │
│                                         │
│ 🔄设计 🛠Python 📐模块 🎯最佳实践       │
│                                         │
│ [查看原文]                              │
└─────────────────────────────────────────┘
```

## 3. Props / Emits

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `doc` | `KnowledgeDoc` | - | 知识文档 |
| `relevance` | `number` | `0` | 相关度 (0-100) |

### Emits

| 事件 | 载荷 | 说明 |
|------|------|------|
| `open` | `{ docId: string }` | 打开原文 |

## 4. 子组件

| 组件 | 说明 |
|------|------|
| `DocHeader` | 文档标题 (复用) |
| `DocTags` | 四维标签 (复用) |
| `RelevanceBadge` | 相关度标签 |

## 5. 交互逻辑

- 点击卡片 → 打开文档原文
- 相关度颜色：>80% 绿色，60-80% 黄色，<60% 灰色

## 6. 样式规范

- 卡片圆角：8px
- 相关度标签：右上角，颜色根据分数变化
- 边框：左侧 3px 高亮条
