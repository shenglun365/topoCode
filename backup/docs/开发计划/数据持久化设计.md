## 1. 存储分层

```
┌──────────────────────────────────────────────────────────┐
│  前端 (Electron Renderer + Main)                         │
│                                                          │
│  electron-store  (Main Process)                          │
│  ├── 用户设置: 主题/语言/窗口位置/后端端口               │
│  ├── 最近项目列表                                         │
│  └── 受信任的目录路径                                     │
│                                                          │
│  localStorage / Pinia Persist  (Renderer)                │
│  ├── UI 临时状态: 面板展开/折叠/宽度                     │
│  └── 最后访问页面/路由                                   │
├──────────────────────────────────────────────────────────┤
│  后端 (Python)                                           │
│                                                          │
│  SQLite  (关系型数据)                                    │
│  ├── 项目元数据 (projects)                               │
│  ├── 文件树快照 (file_snapshots)                         │
│  ├── 分析任务 (analysis_tasks)                           │
│  ├── 分析报告 (analysis_reports)                         │
│  ├── 知识文档 (knowledge_docs)                           │
│  ├── Session 记录 (coder_sessions)                       │
│  ├── 对话消息 (chat_messages)                            │
│  ├── Spec 文档 (spec_docs)                               │
│  ├── Agent 任务 (agent_tasks)                            │
│  └── 配置 (configs): 模型/Agent/SKILL                    │
│                                                          │
│  ChromaDB  (向量数据库)                                  │
│  ├── 代码片段 embedding                                  │
│  ├── 知识文档 embedding                                  │
│  └── 对话上下文 embedding                                │
│                                                          │
│  文件系统                                                │
│  ├── 上传的源码项目 (软链接或副本)                       │
│  ├── Tree-sitter 解析缓存                                │
│  ├── 导出的知识文档 (Markdown)                           │
│  └── 应用日志                                            │
└──────────────────────────────────────────────────────────┘
```

## 2. electron-store 键值设计

```typescript
// Main Process: electron-store 存储结构
interface AppStore {
  // 窗口
  windowBounds: { x: number; y: number; width: number; height: number };
  windowMaximized: boolean;

  // 后端
  backendPort: number;           // 默认 18080
  pythonPath: string;            // Python 解释器路径

  // 项目
  recentProjects: Array<{
    id: string;
    name: string;
    path: string;
    lastOpened: number;          // timestamp
  }>;

  // 设置
  theme: 'dark' | 'light' | 'system';
  language: 'zh' | 'en';
  autoStartBackend: boolean;     // 启动时自动启动后端
  backendAutoRestart: boolean;   // 后端崩溃自动重启
}
```

## 3. SQLite 表结构 (核心表)

```sql
-- 项目
CREATE TABLE projects (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    path TEXT NOT NULL UNIQUE,
    language TEXT,
    file_count INTEGER DEFAULT 0,
    last_modified REAL,
    sync_status TEXT DEFAULT 'synced',  -- synced/changed/error
    analysis_progress REAL DEFAULT 0,
    created_at REAL,
    updated_at REAL
);

-- 文件快照
CREATE TABLE file_snapshots (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    path TEXT NOT NULL,
    name TEXT NOT NULL,
    extension TEXT,
    hash TEXT,
    size INTEGER,
    ast_cached INTEGER DEFAULT 0,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 分析任务
CREATE TABLE analysis_tasks (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    type TEXT NOT NULL,       -- full-parse/ast-gen/call-chain/dataflow/dep-analysis
    status TEXT DEFAULT 'pending',  -- pending/running/done/failed
    target_files TEXT,        -- JSON array
    progress REAL DEFAULT 0,
    result_summary TEXT,
    created_at REAL,
    finished_at REAL,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 知识文档
CREATE TABLE knowledge_docs (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT,              -- Markdown
    type TEXT DEFAULT 'document',  -- project/document
    status TEXT DEFAULT 'draft',   -- draft/pending/reviewed
    dimensions TEXT,           -- JSON: { lifecycle, techStack, abstraction, attribute }
    source_task_id TEXT,
    favorite INTEGER DEFAULT 0,
    pinned INTEGER DEFAULT 0,
    created_at REAL,
    updated_at REAL
);

-- AI 对话 Session
CREATE TABLE coder_sessions (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    type TEXT DEFAULT 'general',  -- project/general/history
    project_id TEXT,
    status TEXT DEFAULT 'active',
    created_at REAL,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 对话消息
CREATE TABLE chat_messages (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL,        -- user/assistant
    type TEXT DEFAULT 'text',  -- text/context/spec/task/error
    content TEXT NOT NULL,
    metadata TEXT,             -- JSON: context/spec/task 等附加数据
    created_at REAL,
    FOREIGN KEY (session_id) REFERENCES coder_sessions(id)
);

-- LLM 模型配置
CREATE TABLE model_configs (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    type TEXT NOT NULL,        -- ollama/openai/custom
    model TEXT NOT NULL,
    endpoint TEXT NOT NULL,
    api_key TEXT,
    is_default INTEGER DEFAULT 0,
    status TEXT DEFAULT 'unknown',  -- online/offline/error
    created_at REAL
);

-- CLI Agent 配置
CREATE TABLE agent_configs (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    path TEXT NOT NULL,
    args TEXT,                 -- JSON array
    is_default INTEGER DEFAULT 0,
    status TEXT DEFAULT 'unknown',
    created_at REAL
);
```

## 4. ChromaDB 集合设计

| 集合名 | 用途 | Embedding 维度 |
|--------|------|----------------|
| `code_snippets` | 代码片段向量 (函数/类级) | 768 (推荐 all-MiniLM-L6-v2) |
| `knowledge_docs` | 知识文档全文向量 | 768 |
| `chat_context` | 对话历史上下文 | 768 |

Embedding 模型: 通过 ModelService 路由，默认使用 all-MiniLM-L6-v2 (本地 sentence-transformers 或云端 API)。

## 5. 数据生命周期

```
项目导入:
  文件夹选择 → 递归遍历文件 → SQLite: file_snapshots → 计算文件哈希

代码分析:
  创建任务 → Tree-sitter 解析 → AST 写入缓存文件
                              → 结构化结果写入 analysis_reports
                              → 代码片段 embedding → ChromaDB

知识提取:
  ExtractDialog → 用户选择标签 → SQLite: knowledge_docs
                               → MD 全文 embedding → ChromaDB

AI 对话:
  发送消息 → 意图分析 → ChromaDB 检索上下文
                     → LLM 生成回复
                     → SQLite: chat_messages
                     → 可选: embedding 写入 ChromaDB (chat_context)

设置修改:
  electron-store.set → 同步到 Pinia → 保存到后端的 configs 表
```

---

## 6. 备份与导出

- **知识库导出**: 选中文档 → 导出为 `.md` 文件到指定目录
- **配置导出**: 模型/Agent 配置 → 导出 JSON 文件
- **SQLite 备份**: 定时备份或手动导出 `.db` 文件
- **ChromaDB**: 不单独备份，可从 SQLite 重建 embedding 索引
