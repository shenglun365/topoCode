| agent | Agent任务状态 | coder |

## 五、通讯协议

### 1. 前端组件间通讯

**Pinia Store (状态管理)**:
```typescript
// 示例: navigation store
interface NavigationState {
  currentPage: 'home' | 'analysis' | 'knowledge' | 'coder' | 'user';
  breadcrumbs: Breadcrumb[];
}

// 组件通过 store 订阅状态变化
const navigation = useNavigationStore();
watch(() => navigation.currentPage, (page) => {
  // 更新UI
});
```

**事件总线 (跨组件事件)**:
```typescript
// 使用 Mitt 或 Vue 的自定义事件
const eventBus = mitt();

// 发送事件
eventBus.emit('file-selected', { filePath, content });

// 监听事件
eventBus.on('file-selected', (data) => {
  // 处理文件选中
});
```

### 2. 前端 ↔ Electron Main Process (IPC)

**IPC 通道定义**:
```typescript
// preload.ts
contextBridge.exposeInMainWorld('electronAPI', {
  // 后端管理
  backend: {
    start: () => Promise<void>,
    stop: () => Promise<void>,
    status: () => Promise<BackendStatus>,
    onStatusChange: (cb: (status: BackendStatus) => void) => void,
  },
  // 项目管理
  project: {
    import: (path: string) => Promise<Project>,
    list: () => Promise<Project[]>,
    delete: (id: string) => Promise<void>,
  },
  // 存储
  store: {
    get: (key: string) => Promise<any>,
    set: (key: string, value: any) => Promise<void>,
  },
  // 窗口控制
  window: {
    toggleLeftPanel: () => void,
    toggleRightPanel: () => void,
    zoomIn: () => void,
    zoomOut: () => void,
  },
});
```

**IPC 消息格式**:
```typescript
interface IPCMessage {
  channel: string;
  payload: any;
  callback?: (result: any) => void;
}
```

### 3. 前端 ↔ Python 后端 (HTTP + WebSocket)

**REST API 规范**:
```typescript
// 统一响应格式
interface APIResponse<T> {
  code: number;        // 0=成功, 1xxx=参数错误, 2xxx=业务错误, 3xxx=系统错误
  message: string;
  data: T;
}

// 示例: 项目导入
POST /api/projects/import
Request:
{
  "path": "/home/user/project",
  "language": "python"
}
Response:
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "proj-123",
    "name": "project",
    "fileCount": 128
  }
}
```

**WebSocket 事件**:
```typescript
// 任务进度
socket.on('task:progress', (data) => {
  // data: { taskId, progress, total, current }
});

// AI 流式回复
socket.on('ai:stream', (data) => {
  // data: { sessionId, chunk, done }
});

// 后端状态
socket.on('backend:status', (data) => {
  // data: { status: 'running' | 'stopped' | 'error' }
});
```

## 七、错误处理策略

### 前端错误处理
```typescript
// 统一错误处理
class AppError extends Error {
  constructor(
    public code: number,
    public message: string,
    public details?: any
  ) {
    super(message);
  }
}

// 组件级错误边界
<template>
  <ErrorBoundary :fallback="errorFallback">
    <ChildComponent />
  </ErrorBoundary>
</template>
```

### 后端错误处理
```python
# FastAPI 异常处理
@app.exception_handler(APIException)
async def api_exception_handler(request, exc):
    return JSONResponse(
        status_code=exc.status_code,
        content={
            "code": exc.code,
            "message": exc.message,
            "data": None
        }
    )
```

## 十、开发规范

### 文件命名
- 组件: `PascalCase.vue` (如 `TaskCard.vue`)
- Store: `camelCase.ts` (如 `analysis.ts`)
- Service: `PascalCase.ts` (如 `ProjectService.ts`)
- 工具函数: `camelCase.ts` (如 `formatDate.ts`)

### 目录结构
```
src/
├── components/        # 通用组件
├── pages/            # 页面组件
├── stores/           # Pinia Store
├── services/         # Service 层
├── composables/      # 组合式函数
├── types/            # TypeScript 类型
├── utils/            # 工具函数
├── assets/           # 静态资源
└── styles/           # 全局样式
```

### 代码风格
- 使用 ESLint + Prettier
- TypeScript 严格模式
- Vue 3 Composition API + `<script setup>`
- CSS 变量 + scoped CSS

### 图标规范
- **所有 UI 图标统一使用 Heroicons** (`@heroicons/vue/24/outline`)
- 不使用 Unicode emoji 或字体图标
- 按钮图标尺寸: `w-4 h-4`
- 活动栏图标尺寸: `w-5 h-5`
- 空状态图标尺寸: `48x48px`
- 导入方式: `import { XxxIcon } from '@heroicons/vue/24/outline'`
