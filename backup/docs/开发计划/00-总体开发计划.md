# TopoOne 总体开发计划

> 基于系统架构设计，拆解为 5 个 Phase + Service 层，每个组件独立设计文档。

---

## 开发阶段总览

```
Phase 1: UI Shell 基础框架 (6 组件)
    ↓
Phase 2: 项目导入 + 代码分析 (8 组件)
    ↓
Phase 3: 知识库 (6 组件)
    ↓
Phase 4: AI 助手 (7 组件)
    ↓
Phase 5: 设置 + 配置 (7 组件)

Service 层: 6 个 Service (贯穿所有 Phase)
```

## Phase 依赖关系

```
Phase 1 (UI Shell) —— 基础框架
    ├── AppShell       ← 整体布局容器 + 面板状态管理
    ├── TopBar          ← 菜单栏 + 面板切换 + 主题
    ├── ActivityBar     ← 5 模块导航入口
    ├── LeftPanel       ← 动态上下文面板 (可折叠/拖拽)
    ├── RightPanel      ← 动态详情面板 (可折叠/拖拽)
    └── StatusBar       ← 全局状态指示

Phase 2 (项目导入 + 代码分析) 依赖 Phase 1
    ├── ProjectCard     ← 项目卡片 (名称/语言/进度/同步)
    ├── ImportZone      ← 拖拽导入区域
    ├── FileTree        ← 文件树浏览
    ├── TaskCard        ← 分析任务卡片 (收藏/置顶)
    ├── TaskReport      ← 分析报告 (AST/调用链/依赖/数据流)
    ├── ExtractDialog   ← 提取知识点对话框 (四维标签)
    ├── ProjectImport   ← 项目根组件 (默认/项目视图切换)
    └── HomeTabBar      ← 项目内多 Tab Card 管理

Phase 3 (知识库) 依赖 Phase 1
    ├── KnowledgeGraph  ← SVG 力导向图谱 (D3.js)
    ├── DimensionFilter ← 四维折叠筛选栏
    ├── KnowledgeCard   ← 知识文档卡片 (标签/状态)
    ├── DocEditor       ← MD 编辑/浏览/预览 (Monaco)
    ├── AnimationPlayer ← 代码执行流程动画播放器
    └── CategoryManager ← 四维标签分类管理

Phase 4 (AI 助手) 依赖 Phase 1 + Phase 3
    ├── SessionTabBar   ← 多 Tab Session 管理
    ├── ChatFlow        ← 对话消息流 + 流式显示
    ├── ChatMessage     ← 消息气泡 (用户/助手)
    ├── ContextCard     ← 上下文检索卡片
    ├── SpecCard        ← Spec 摘要卡片
    ├── TaskStatusCard  ← Agent 任务状态卡片
    └── RightPanelTabs  ← 右面板 4 Tab 切换

Phase 5 (设置与配置) 依赖 Phase 1
    ├── SettingsTabBar  ← 设置页 Tab 导航 (6 项)
    ├── ModelConfig     ← LLM 模型配置管理
    ├── AgentManager    ← 外部 CLI Agent 配置
    ├── SkillManager    ← SKILL 校验拓展开关
    ├── GeneralSettings ← 主题/语言/HTTP 服务
    ├── PluginManager   ← 语言解析器插件管理
    └── AboutPage       ← 版本信息/检查更新

Service 层 (贯穿所有 Phase)
    ├── ProjectService  ← Phase 2
    ├── AnalysisService ← Phase 2
    ├── KnowledgeService ← Phase 3
    ├── CoderService    ← Phase 4
    ├── ModelService    ← Phase 5
    └── AgentService    ← Phase 4/5
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Electron + Vue 3 + TypeScript + Vite |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| UI 组件 | 自研 (基于 Catppuccin 主题) |
| 样式 | CSS 变量 + scoped CSS |
| 图谱 | D3.js / Cytoscape.js |
| 代码编辑 | Monaco Editor |
| Markdown | Markdown-it + 自定义渲染器 |
| 后端 | Python 3.12 + FastAPI |
| 解析 | Tree-sitter |
| 存储 | SQLite + ChromaDB |
| 图计算 | NetworkX |

---

## 开发原则

1. **组件独立**: 每个组件独立设计文档，明确 Props/Events/Slots
2. **渐进实现**: Phase 1 先跑通 UI Shell，后续 Phase 逐步填充
3. **Service 先行**: 每个 Phase 对应的 Service 接口先定义，UI 组件对接接口
4. **原型参考**: 以当前 HTML/CSS/JS 原型为 UI 参考，迁移为 Vue 组件
5. **LLM 外部化**: 不内置本地模型，用户自由选择本地/云端
